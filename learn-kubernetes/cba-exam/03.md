# 03. TypeScript Compile

**Domain:** Development Workflow (24%)

## Concept Refresher

The app is **TypeScript**. **`yarn tsc`** (or `tsc --noEmit`) typechecks. CI should fail on errors.

`yarn tsc:full` / incremental `tsconfig` may exist. Frontend and backend each have tsconfig extending root.

Installing a plugin often means **importing it in `.ts`/`.tsx`** — that is “customizing TypeScript”, still CBA-in-scope. A type error after `yarn add` means you forgot to register or the plugin API changed.

`any` everywhere is not the platform standard; the exam still cares that **tsc is how you compile/check**.
