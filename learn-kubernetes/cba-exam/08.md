# 08. Deploy to Production

**Domain:** Infrastructure (22%)

## Concept Refresher

Production checklist:

| Item | Dev | Prod |
| --- | --- | --- |
| Database | SQLite | **PostgreSQL** |
| Auth | Guest | GitHub/Google/OIDC, org sync |
| Process | `yarn start` | Built **backend** (container/K8s) |
| URLs | localhost | Real `baseUrl`, HTTPS |
| Secrets | local yaml | K8s Secrets / vault / env |
| HA | one process | multiple replicas + Postgres |
| Integrations | optional token | tokens for discovery |

Deploy patterns: Kubernetes Deployment + Service + Ingress; Helm community charts; VM + systemd. CBA cares about **what must change**, not a specific chart.

Scale: backend is stateless if sessions/DB are external. Sticky sessions sometimes for auth — prefer proper session store / OIDC.
