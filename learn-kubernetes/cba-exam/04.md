# 04. Yarn / NPM Dependencies

**Domain:** Development Workflow (24%)

## Concept Refresher

Backstage apps use **Yarn** (Berry/v4 in current create-app) with a **lockfile**. `yarn install` downloads workspaces.

Add a package:

```bash
yarn --cwd packages/app add @backstage/plugin-catalog
# or: yarn workspace app add @package
yarn workspace backend add @backstage/plugin-search-backend
```

`npm install` may work but **Yarn is the documented path**. Don’t mix lockfiles.

`resolutions` / `yarn.lock` keep Backstage package versions aligned — random `npm i latest` of one `@backstage/*` breaks the app.

`node_modules` is not committed. CI: `yarn install --immutable` (or frozen lockfile).
