# 12. Context Propagation

**Domain:** The OpenTelemetry API and SDK (46%)

## Concept Refresher

**Context** carries span identity (and baggage) across calls.

**W3C Trace Context** (default):

| Header | Content |
| --- | --- |
| `traceparent` | `00-<trace-id>-<span-id>-<flags>` |
| `tracestate` | vendor key=value list |

Flags bit: sampled (`01`) vs not.

**W3C Baggage** header: comma key=value; **propagated** for app logic (tenant, experiment). **Not** automatically copied onto spans (you may `baggage` → span attributes explicitly). Don’t put secrets or huge values.

**Propagator** injects on outbound, extracts on inbound. `OTEL_PROPAGATORS=tracecontext,baggage`. Legacy: `b3`, `jaeger`.

In-process: context is stored in thread-local / async context. HTTP instrumentation injects headers.

Broken traces: missing extract on ingress, missing inject on egress, or overwriting context.

This competency also appears in **domain 4** (debugging broken propagation).
