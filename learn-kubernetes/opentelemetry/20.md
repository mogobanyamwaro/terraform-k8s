# 20. Collector Connectors, Operator, and Export

**Domain:** The OpenTelemetry Collector (26%)

## Concept Refresher

**Connectors** join pipelines:

- `spanmetrics` — traces → RED-ish metrics
- `forward` — pipeline to pipeline
- `exceptions` / others in contrib

**Exporters (examples):** `otlp`, `otlphttp`, `debug`, `prometheus`, `prometheusremotewrite`, `kafka`, vendor exporters in contrib.

**Receivers:** `otlp`, `prometheus`, `filelog`, `jaeger`, `zipkin`, `hostmetrics`, `k8s_cluster`.

**Operator** (Kubernetes):

- `OpenTelemetryCollector` CR — deploy Collector
- `Instrumentation` CR — inject SDK/agent env

**TLS/auth** on OTLP: Collector can require client certs; apps set `OTEL_EXPORTER_OTLP_HEADERS`.

Keep **core vs contrib** in mind when an exam snippet uses `filelog` (contrib).

This closes domain 3. Domain 4 is how you **debug** these graphs.
