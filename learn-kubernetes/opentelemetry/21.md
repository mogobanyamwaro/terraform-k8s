# 21. Debugging Pipelines and Context

**Domain:** Maintaining and Debugging Observability Pipelines (10%)

## Concept Refresher

**Missing traces**

1. SDK no-op / `OTEL_SDK_DISABLED` / wrong exporter
2. Sampler dropped (`always_off`, ratio, ParentBased mismatch)
3. Collector component not in pipeline
4. Wrong endpoint/port/protocol
5. **Broken propagation** (many roots, no parent)

**Tools**

| Tool | Where |
| --- | --- |
| `OTEL_TRACES_EXPORTER=console` | SDK |
| Collector `debug` exporter | Pipeline |
| `zpages` (`/debug/tracez`) | Collector extension |
| `service.telemetry` logs | Collector process |
| `logging` exporter (legacy name) | Older YAML |

**Context debugging:** log `traceparent` on ingress/egress. Confirm same trace-id. Check propagator list. Async: context not attached.

**zpages** show in-memory span stats — not a backend.

Enable Collector logs to `debug` temporarily. Don’t leave `verbosity: detailed` in prod.
