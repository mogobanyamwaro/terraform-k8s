# 14. Sampling and OTLP Export

**Domain:** The OpenTelemetry API and SDK (46%)

## Concept Refresher

**Head sampling (SDK)** at span start:

| Sampler | Behaviour |
| --- | --- |
| `always_on` | Record all |
| `always_off` | Record none (context may still propagate) |
| `traceidratio` | Random fraction of **root** traces |
| `parentbased_*` | **Respect parent** sampled flag; ratio only for roots |

Production default is often **ParentBased(TraceIdRatio)**. Without ParentBased, a service might sample a child while the parent was dropped → **broken** traces.

**Tail sampling** is a **Collector** processor (`tail_sampling`) after the trace is complete — error traces, slow traces. Needs a **gateway** and often **trace-ID aware load balancing**.

**OTLP** is the native protocol (protobuf over gRPC or HTTP). Prefer OTLP to the Collector; Collector fans out to Jaeger/Prometheus/Tempo.

Compression, headers, TLS: `OTEL_EXPORTER_OTLP_HEADERS`, certificates. Retry/backoff is SDK exporter behaviour.
