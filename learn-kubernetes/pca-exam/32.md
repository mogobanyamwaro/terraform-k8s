## Answers

**Q1: B.** `service_sent_bytes_total`. Base unit `bytes`, `_total` suffix for a counter, snake_case, unit before `_total`.

**Q2: B.** Never expose a pre-computed rate. The counter plus `rate()` lets any consumer pick any window and aggregate correctly.

**Q3: B.** Those six. Using them as base names collides with histogram, summary, counter, and info conventions.

**Q4: B.** Seconds, always, even if the source reports milliseconds. Convert in the exporter.

**Q5: D.** 10 explicit boundaries plus the implicit `+Inf` gives 11 `_bucket` series, plus `_sum` and `_count`, so 13 per label combination. 13 x 4 = 52. See the note below, because the wording of "buckets" decides whether `+Inf` is included.

**Q6: D.** `quantile`-labelled series come from **summaries**, not histograms.

**Q7: B.** `Info`, which in Prometheus text format renders as `<name>_info` gauge set to 1.

**Q8: B.** Multiprocess mode with a shared directory, otherwise each scrape hits a random worker and you see only that worker's numbers.

**Q9: B.** Variable dimensions belong in labels, not in metric names.

**Q10: B.** Names beginning with `__` are reserved for internal use.

**Q11: B.** Two-level health. Prometheus to exporter is fine; exporter to backend is not.

**Q12: B.** kube-state-metrics, which reflects API object state.

**Q13: B.** cAdvisor, embedded in the kubelet at `/metrics/cadvisor`.

**Q14: B.** The metric is an absolute Unix timestamp, so subtract `time()` and convert to days.

**Q15: A.** Address into `__param_target`, target into `instance`, then point `__address__` at the exporter.

**Q16: B.** The textfile collector.

**Q17: B.** Parse errors and file age.

**Q18: B.** Textfile collector, because the metric is machine-scoped and node_exporter is already a target there.

**Q19: B.** `PUT` replaces the whole group.

**Q20: B.** Target labels win by default, and the pushed label is preserved with the `exported_` prefix.

**Q21: B.** `push_time_seconds`, plus `push_failure_time_seconds`.

**Q22: B.** Keep the push to just the batch metrics.

**Q23: B.** A boundary at the threshold in **base units**, so `0.5`, not `500`.

**Q24: B.** A gauge, since the value goes up and down.

**Q25: B.** A callback gauge, avoiding duplicated state and timer lag.

**Q26: B.** On scrape, so data is fresh and there is no cache staleness.

**Q27: B.** Never set your own timestamps, and never set `job` or `instance`.

**Q28: C.** 16 x 8 = 128.

**Q29: B.** `avg` across cores of the idle rate, subtracted from 1. Option C sums non-idle rates, which gives core-seconds rather than a fraction, and would need dividing by core count.

**Q30: B.** Agent mode with remote write is the designed answer for spoke-to-hub collection.

### Note on Q5

The arithmetic matters, so be deliberate about it:

```text
explicit buckets            = 10
implicit +Inf bucket        =  1
_bucket series per combo    = 11
_sum                        =  1
_count                      =  1
total per label combination = 13
x 4 combinations            = 52
```

The general formula is **series = (buckets + 1 + 2) x label combinations**, where `buckets` is the number of **explicit** boundaries. If a question states "10 buckets" meaning boundaries **including** `+Inf`, then it is `(10 + 2) x combos = 48`. Read the wording: "10 explicit buckets" means `+Inf` is extra.

## Exam tips

The mistakes this drill is built to expose:

- Histogram series arithmetic. Count `+Inf`, `_sum`, and `_count`.
- **Summaries** have `quantile` labels; **histograms** have `le` labels. Do not swap them.
- Base units only. `le="0.5"`, never `le="500"`.
- Never expose rates, ratios, or percentages. Expose counters.
- `up` versus `<system>_up` versus `probe_success` are three different health questions.
- kube-state-metrics is **object state**; cAdvisor is **container usage**; node_exporter is **host resources**.
- Pushgateway needs `honor_labels: true`, has no TTL, and destroys per-job `up`.
- Textfile collector for **machine** jobs; Pushgateway for **service** jobs.
- Cardinality multiplies. Cores x modes, buckets x label combinations.
- Agent mode plus remote write is the answer for central collection, not the Pushgateway.
