# 02. Drift, Reconciliation, and Continuous

**Domain:** GitOps Terminology (20%)

## Concept Refresher

**Drift**: actual state has moved (or is moving) **away from desired state**. Causes: manual `kubectl`, broken controllers, human “hotfixes”, failed applies, someone scaling a Deployment in the console.

**Reconciliation**: process of making **actual match desired**. Triggered whenever there is **divergence**:

1. Desired state **changed** on purpose (new Git commit)
2. Actual state **drifted** (hotfix, failure)

Unlike traditional CI/CD, GitOps reconciliation is **not** only a preset pipeline trigger.

**Continuous** (glossary): reconciliation **continues to happen**, **not** that it must be instantaneous. A 3-minute Git interval is still continuous.

## Exam tips

- Two divergence sources: **new desired** and **drift**.
- Continuous ≠ realtime.
