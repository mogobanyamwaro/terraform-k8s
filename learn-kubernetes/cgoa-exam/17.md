# 17. State Store Systems

**Domain:** Tooling (14%)

## Concept Refresher

**Git** (GitHub, GitLab, Bitbucket, Gitea, self-host): canonical.

**Alternatives** that can qualify:

- **OCI registries** storing config artifacts (Flux OCIRepository, Helm OCI)
- Other VCS with history + ACL (if used immutably)
- Signed artifact stores

**Not** alternatives:

- Confluence/wiki
- Slack
- Live etcd
- S3 bucket of `latest.yaml` overwritten in place with no versions
- A database of “current” without history

Precautions: branch protection, SSO, audit log, least-privilege deploy keys (read-only for the agent), no force-push on prod, separate credentials per cluster.

GitOps name comes from Git; OpenGitOps **allows** other stores that meet the bar.

## Hands-on

Compare `git log` on the config repo with `kubectl get --show-managed-fields`. History lives in Git, not as a replacement for etcd.

## Exam tips

- Git is default, **not exclusive**.
- etcd = **actual**, Git = **desired**.
