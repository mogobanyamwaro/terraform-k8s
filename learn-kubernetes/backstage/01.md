# 01. Create and Run Locally

**Domain:** Development Workflow (24%)

## Concept Refresher

Scaffold with **`npx @backstage/create-app@latest`** (or `yarn create`). This generates a **standalone app** (not a fork of the Backstage monorepo): `packages/app` (frontend), `packages/backend`, `app-config.yaml`.

Local run: **`yarn start`** — webpack/Vite frontend (default **3000**) and Node backend (**7007**). Guest auth works out of the box.

`yarn start --filter=...` / workspace scripts exist; exam default is `yarn start` from the app root.

Do not confuse with running the **Backstage OSS monorepo** (`contrib` / core development). CBA is about **your** created app.
