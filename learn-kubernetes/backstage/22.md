# 22. Theming, Sidebar, and App Shell

**Domain:** Customizing Backstage (32%)

## Concept Refresher

**Theme:** Backstage wraps MUI in `@backstage/theme` (`createUnifiedTheme`, palettes, page themes). Override in `packages/app` and pass into `createApp({ themes: [...] })` or `UnifiedThemeProvider`. Logo, colours, typography without forking plugins.

**Sidebar (`Root.tsx`):** `Sidebar`, `SidebarItem`, `SidebarDivider`, groups. Icons from Material icons. This is the usual “add a link to Docs / Catalog / Create”.

**App shell:** header, user settings, search bar — `createApp` components / `Root`. Sign-out, theme toggle live here.

**configApi** can drive titles (`app.title`) shown in the shell.

Production branding = theme + `app.title` + logo assets in `packages/app`. Not a catalog annotation.

Together with 17–21 this is the **32%** customize domain: FE/BE split, install, compose plugins, React, MUI, shell/theme.
