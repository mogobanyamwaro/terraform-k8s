# 21. Material UI in Backstage

**Domain:** Customizing Backstage (32%)

## Concept Refresher

Backstage’s UI is built on **Material UI** (MUI). create-app historically used MUI v4 (`@material-ui/core`); newer apps may use MUI v5 (`@mui/material`) via Backstage’s theme wrappers. Exam wording: **Material UI**.

Use layout primitives already in the app:

- `Grid`, `Button`, `Typography`, `Card`, `Paper`, `Box`
- Backstage wrappers: `InfoCard`, `Progress`, `EmptyState`, `CodeSnippet` from `@backstage/core-components`

```tsx
import Grid from '@material-ui/core/Grid';
import { Button, Typography } from '@material-ui/core';
import { InfoCard } from '@backstage/core-components';

<Grid container spacing={3}>
  <Grid item md={6}>
    <InfoCard title="Status">
      <Typography variant="body1">OK</Typography>
      <Button variant="contained" color="primary">Refresh</Button>
    </InfoCard>
  </Grid>
</Grid>
```

Prefer **core-components** + MUI, not a second design system. Spacing/`Grid` on `EntityPage` is the usual pattern.

`makeStyles` / `useTheme` / `sx` (v5) appear in app code. You do not need every prop memorised.
