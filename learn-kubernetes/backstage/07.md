# 07. Configure Backstage

**Domain:** Infrastructure (22%)

## Concept Refresher

**`app-config.yaml`** is the main config (YAML). Later files override earlier (`app-config.yaml`, `app-config.production.yaml`, `app-config.local.yaml`).

`${ENV_VAR}` substitution is common.

Important keys:

```yaml
app:
  title: Example
  baseUrl: http://localhost:3000
backend:
  baseUrl: http://localhost:7007
  listen: { port: 7007 }
  database:
    client: better-sqlite3   # dev
    # client: pg             # prod
organization:
  name: Acme
catalog:
  locations: [...]
auth:
  environment: development
  providers: { ... }
integrations:
  github:
    - host: github.com
      token: ${GITHUB_TOKEN}
```

`backend.cors.origin` must allow the frontend origin. Wrong `baseUrl` breaks auth cookies and TechDocs.

Do not put production secrets in Git.
