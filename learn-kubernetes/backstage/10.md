# 10. Auth, Database, and Integrations (Prod Wiring)

**Domain:** Infrastructure (22%)

## Concept Refresher

**Auth providers:** GitHub, Google, Microsoft, OIDC, Auth0, guest (dev). `auth.session` / cookie. Sign-in resolver maps IdP identity → catalog User (or sign-in without catalog user).

**Org:** GitHub org provider / LDAP / static Users and Groups in YAML.

**Integrations:** host + token or GitHub App for scm. Needed for: register URL locations, scaffolder publish, TechDocs in private repos, catalog discovery.

**Permission framework** (optional): fine-grained catalog/scaffolder RBAC — know it exists; deep policy YAML is advanced.

**Search:** collators need backend plugins running.
