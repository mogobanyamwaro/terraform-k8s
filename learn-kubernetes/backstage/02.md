# 02. Local Development Workflow

**Domain:** Development Workflow (24%)

## Concept Refresher

Yarn **workspaces**: root `package.json` private workspaces `packages/*`. Changes in `packages/app` hot-reload the UI. Backend often restarts on change.

Useful scripts (names can vary slightly by create-app version):

| Script | Job |
| --- | --- |
| `yarn start` | Dev frontend + backend |
| `yarn workspace app start` | Frontend only |
| `yarn workspace backend start` | Backend only |
| `yarn tsc` | Typecheck |
| `yarn lint` / `yarn test` | Quality |
| `yarn backstage-cli versions:bump` | Upgrade Backstage packages |

`app-config.local.yaml` overrides `app-config.yaml` for secrets and local URLs — **do not commit secrets**.

Debug catalog: backend logs; Catalog → inspect entity; `/api/catalog/entities`.
