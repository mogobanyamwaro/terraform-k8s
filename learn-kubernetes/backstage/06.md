# 06. Backstage Framework

**Domain:** Infrastructure (22%)

## Concept Refresher

Backstage is an **open platform for building developer portals** (IDP UX): catalog, templates (Scaffolder), TechDocs, search, plus **plugins**.

**Core building blocks**

| Piece | Role |
| --- | --- |
| Software Catalog | Inventory of Components, APIs, … |
| Software Templates | Golden-path scaffolding |
| TechDocs | Docs-like-code in the portal |
| Search | Unified search |
| Auth / Identity | Who is the user; org from IdP or catalog Users/Groups |
| Kubernetes / CI plugins | Optional integrations |

The **framework** = plugin architecture + catalog model + config. You **compose** an app; you do not run “the” single Spotify instance.

CNCF: Backstage is the usual **developer portal** example in platform engineering. CBA tests the **product**, not DORA theory.
