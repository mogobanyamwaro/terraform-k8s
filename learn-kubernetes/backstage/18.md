# 18. Install and Register Plugins

**Domain:** Customizing Backstage (32%)

## Concept Refresher

**Install** (Yarn workspaces):

```bash
yarn workspace app add @backstage/plugin-kubernetes
yarn workspace backend add @backstage/plugin-kubernetes-backend
```

(`yarn --cwd packages/app add ...` is the same idea.)

**Register frontend** — import in `packages/app` (`App.tsx` routes and/or `EntityPage.tsx` cards/tabs). A dependency in `package.json` **without** a route/card does nothing visible.

**Register backend** — `backend.add(import('@backstage/plugin-kubernetes-backend'))` (new backend system) or the older `createRouter` wiring in `packages/backend/src/index.ts` / plugin files.

**Configure** — `app-config.yaml` (`kubernetes.clusterLocatorMethods`, plugin-specific keys). Restart backend after config.

Docs for each plugin show **both** packages and the exact wire-up. Follow the plugin README; do not invent imports.

## Exam tips

- **add ≠ register ≠ configure** — three steps.
- Empty UI after add → missing `App.tsx` / `EntityPage` / `backend.add`.
