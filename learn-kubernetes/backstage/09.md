# 09. Client–Server Architecture

**Domain:** Infrastructure (22%)

## Concept Refresher

```text
Browser (React SPA, packages/app)
    HTTPS
Backstage backend (Node, packages/backend)  :7007
    |-- catalog plugin
    |-- scaffolder
    |-- techdocs (or external generator)
    |-- auth
    |-- other backend plugins
    PostgreSQL
    GitHub / K8s / CI APIs
```

The **browser never** talks to the catalog database directly. Frontend plugins call **backend plugin HTTP APIs**.

Frontend plugin = UI. Backend plugin = data/secrets/integrations. Many features need **both** packages.

TechDocs can generate **in backend** or in CI (techdocs-cli) and store in S3/GCS — still served via backend.

Websockets/events exist for some plugins; exam: request/response to backend.
