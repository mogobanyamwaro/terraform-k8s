# Certified Kubernetes Security Specialist Practice

This folder mirrors the flat `learn-kubernetes/exam` layout, but the tasks are for CKS.

The files are written as practical exam drills:

- `Question` gives the scenario and required outcome.
- `Answer` gives commands and YAML that solve it.
- `Verify` gives quick checks.
- `Exam tips` gives the short memory hooks.

Source outline checked against the CNCF CKS page and curriculum repository on 2026-08-07.


## Universal CKS Flow

When a task looks unfamiliar, use this order:

```bash
# 1. Check namespace and context
kubectl config current-context
kubectl config view --minify --output 'jsonpath={..namespace}'; echo

# 2. Inspect the object
kubectl get <resource> -n <namespace>
kubectl describe <resource> <name> -n <namespace>
kubectl get <resource> <name> -n <namespace> -o yaml

# 3. Check logs or events
kubectl logs <pod> -n <namespace>
kubectl get events -n <namespace> --sort-by=.lastTimestamp

# 4. Verify authorization decisions
kubectl auth can-i <verb> <resource> -n <namespace>
kubectl auth can-i <verb> <resource> --as=<user> -n <namespace>

# 5. Use server-side validation where useful
kubectl apply --dry-run=server -f file.yaml
```

## Fast File Editing Pattern

For immutable Pod fields, export, edit, delete, recreate:

```bash
kubectl get pod app -n secure -o yaml > app.yaml
vi app.yaml
kubectl delete pod app -n secure
kubectl apply -f app.yaml
```

For Deployments, prefer patch or edit:

```bash
kubectl edit deployment app -n secure
kubectl rollout status deployment/app -n secure
```

## Security Defaults To Remember

- Use least privilege RBAC.
- Disable automounted service account tokens when not needed.
- Prefer `runAsNonRoot: true`.
- Set `allowPrivilegeEscalation: false`.
- Drop Linux capabilities with `drop: ["ALL"]`.
- Use `seccompProfile.type: RuntimeDefault`.
- Prefer `readOnlyRootFilesystem: true`.
- Use NetworkPolicy default-deny plus explicit allows.
- Scan images and manifests before deployment.
- Investigate runtime alerts from audit logs, container runtime logs, and Falco.
