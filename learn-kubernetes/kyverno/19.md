# 19. Variables, API Calls, and Autogen

**Domain:** Writing Policies (32%)

## Concept Refresher

**Variables** — `{{ JMESPath }}`:

```text
{{ request.object.metadata.name }}
{{ request.namespace }}
{{ request.operation }}
{{ request.userInfo.username }}
{{ request.userInfo.groups }}
```

**context** loads extra data:

```yaml
context:
  - name: cms
    configMap:
      name: allowed
      namespace: kyverno
  - name: ns
    apiCall:
      urlPath: "/api/v1/namespaces/{{ request.namespace }}"
      jmesPath: metadata.labels
  - name: images
    imageRegistry:
      reference: "{{ image }}"
```

Use `{{ cms.data.foo }}` in patterns/deny.

**Autogen** — a Pod rule is auto-applied to **controllers** that create Pods (Deployment, DaemonSet, Job, CronJob, StatefulSet, ReplicaSet, …).

Disable:

```yaml
spec:
  autogen:
    podControllers:
      controllers: []
# or annotation pod-policies.kyverno.io/autogen-controllers: none
```

Without autogen, matching **only Pod** misses `kubectl apply -f deployment.yaml` at the **Deployment** object (Pods still created by the controller — admission on Pod may still fire). Know **both** layers.
