# 17. Generation Rules

**Domain:** Writing Policies (32%)

## Concept Refresher

**generate** creates **other** resources when a trigger matches (e.g. Namespace → NetworkPolicy, RoleBinding).

**data** — inline manifest:

```yaml
generate:
  synchronize: true
  apiVersion: networking.k8s.io/v1
  kind: NetworkPolicy
  name: default-deny
  namespace: "{{ request.object.metadata.name }}"
  data:
    spec:
      podSelector: {}
      policyTypes: [Ingress]
```

**clone** — copy an existing object (NetworkPolicy template in a golden NS):

```yaml
generate:
  synchronize: true
  clone:
    namespace: staging
    name: baseline-np
```

**synchronize: true** — Kyverno **owns** the child; user edits get reverted; trigger delete can cascade per `orphanDownstreamOnPolicyDelete`.

**synchronize: false** — fire-and-forget.

`generateExisting: true` — backfill.

Needs RBAC to create the generated kind. Failures show on the policy / UpdateRequest.

Don’t generate the same name from two policies without care.
