# 18. VerifyImage Rules

**Domain:** Writing Policies (32%)

## Concept Refresher

**verifyImages** checks **signatures and attestations** (Sigstore/Cosign) before the workload is admitted.

```yaml
verifyImages:
  - imageReferences:
      - "ghcr.io/org/*"
    attestors:
      - entries:
          - keys:
              publicKeys: |-
                -----BEGIN PUBLIC KEY-----
                ...
    attestations:
      - predicateType: https://slsa.dev/provenance/v1
        attestors: [...]
    mutateDigest: true
    verifyDigest: true
    required: true
```

**Keyed** Cosign vs **keyless** (Fulcio identities, subject/issuer).

`mutateDigest: true` rewrites tag → digest (pin). `verifyDigest` checks digest presence.

Not the same as “image exists in OCI” or policy-as-OCI.

Needs network to Rekor/Fulcio/registry unless air-gapped (TUF/mirrors). Failure → admission deny if Enforce.

ImageVerify can be slow — webhook timeout.
