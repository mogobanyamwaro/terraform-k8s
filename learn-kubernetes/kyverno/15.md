# 15. Background Scans

**Domain:** Writing Policies (32%)

## Concept Refresher

Admission only sees **new** requests. **Background** evaluation walks **existing** objects and writes **PolicyReports** (validate). It does not, by itself, delete violating Pods.

```yaml
spec:
  background: true   # default for many validate policies
```

`background: false` — admission only (faster, no report noise on old stuff).

Background uses the **background-controller**. Needs RBAC to list those kinds.

**mutateExistingOnPolicyUpdate** / **generateExisting** — background-style **changes** to objects already in etcd (dangerous; use carefully).

Kyverno’s own requests: `skipBackgroundRequests: true` (default-ish) avoids loops.

Reports from background can show **fail** while admission was Audit — same policy, two paths.

Don’t expect background validate to **evict** workloads. That’s cleanup policies or human response.
