# 02. YAML Manifests

**Domain:** Fundamentals of Kyverno (18%)

## Concept Refresher

Envelope:

```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-labels
spec:
  validationFailureAction: Enforce
  background: true
  rules:
    - name: check-app
      match:
        any:
          - resources:
              kinds: [Pod]
              namespaces: [prod]
      exclude:
        any:
          - resources:
              names: ["kube-proxy*"]
      validate:
        message: "app label required"
        pattern:
          metadata:
            labels:
              app: "?*"
```

`match.any` = **OR** across entries. `match.all` = **AND**. Same for exclude.

`kinds` uses Kubernetes kind (`Pod`, `Deployment`). Autogen can expand Pod rules to controllers.

`apiVersion` for policies is **`kyverno.io/v1`** (exceptions/cleanup often `v2`).

YAML must indent like any K8s manifest. A rule that both `validate`s and `mutate`s in the **same** rule object is not the usual pattern — split rules.
