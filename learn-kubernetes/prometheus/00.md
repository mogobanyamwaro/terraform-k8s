# Prometheus Certified Associate (PCA) Practice

This folder mirrors the flat `learn-kubernetes/kubernetes` and `learn-kubernetes/kubernetes-security` layout, but the content targets the PCA exam.

Source outline checked against the Linux Foundation PCA certification page and the CNCF curriculum on 2026-08-18.

## Important: PCA Is Not Like CKA or CKS

| | CKA / CKS | PCA |
| --- | --- | --- |
| Format | Performance-based, live terminal | Multiple choice, online proctored |
| Questions | 15-20 tasks | 60 questions |
| Duration | 2 hours | 90 minutes |
| Passing score | 66% (CKA) / 67% (CKS) | 75% (45 of 60) |
| Docs allowed | Yes, one browser tab | No. Closed book |
| Validity | 2 years | 2 years |
| Cost | Varies | 250 USD, one free retake |
| Scheduling window | 12 months | 12 months |
| Results | 24 hours | 24 hours |
| Proctor platform | PSI | PSI |

Because PCA is closed book, you must **memorise**. You cannot look up `histogram_quantile` argument order during the exam. That is why every file here has a `Memorise` or `Exam tips` section.

Budget roughly **90 seconds per question**. Flag anything that takes longer and come back. Later questions sometimes reveal terminology that helps earlier ones.

## Universal PCA Reasoning Flow

When a question looks unfamiliar, walk this order:

```text
1. What metric type is involved?
   counter -> almost always needs rate() or increase()
   gauge   -> use directly, or *_over_time()
   histogram -> _bucket + histogram_quantile(), or _sum / _count for average
   summary -> quantile label already there, cannot re-aggregate quantiles

2. What is the result type they want?
   single number       -> scalar or aggregation without by
   one series per X    -> aggregation ... by (X)
   over a time window  -> range vector [5m] plus a function

3. Does the expression type-check?
   rate() needs a range vector
   sum() needs an instant vector
   histogram_quantile() needs a bucket instant vector with le

4. Are labels compatible?
   binary ops between two vectors need identical label sets
   otherwise use on() / ignoring() / group_left() / group_right()

5. What is the trap in the distractors?
   avg of rate vs rate of avg
   sum then rate  (wrong)  vs  rate then sum  (right)
   irate for alerting (wrong) vs rate for alerting (right)
   quantile aggregated across instances (wrong for summaries)
```

## Prometheus Truths To Remember

- Prometheus **pulls** by default. Pushgateway is the narrow exception for batch jobs.
- Prometheus stores **float64 samples** with millisecond timestamps, plus native histograms.
- A time series is uniquely identified by its **metric name plus the full set of label name/value pairs**.
- `__name__` is the label that holds the metric name.
- Labels starting with `__` are internal and dropped after relabeling, except `__name__`.
- Prometheus is **not** for event logging, billing-grade accuracy, or long-term durable storage on its own.
- Counters only go up. `rate()` handles resets.
- Histograms are **cumulative**. Summaries pre-compute quantiles and cannot be aggregated.
- Alertmanager handles **grouping, inhibition, silencing, and routing**. Prometheus decides **when** an alert fires.
- Reload config with `SIGHUP` or `POST /-/reload` when `--web.enable-lifecycle` is set.
- Always validate with `promtool check config` and `promtool check rules`.
