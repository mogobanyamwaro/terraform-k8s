# Internal Developer Platform (IDP)

## Two meanings (both appear)

1. **Internal Developer Platform** — the whole product (APIs, paths, guardrails).  
2. **Developer portal** — UX (Backstage) on top.

Exam: do not say Backstage **is** the platform.

## Golden path start

Template → repo with CI, chart, `catalog-info.yaml`, owners, CODEOWNERS → GitOps Application.

## Catalog

Who owns it, where is the API, what’s the SLO, what’s the on-call?

## Service catalog (API)

Request a database: CR/composition, not a spreadsheet.

## DX metrics

Time-to-first-deploy, template adoption, “can I find the owner?”, NPS/SPACE satisfaction.
