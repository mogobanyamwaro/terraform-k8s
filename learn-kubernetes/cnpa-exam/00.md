# Certified Cloud Native Platform Engineering Associate (CNPA) Practice

This folder mirrors `pca-exam`, `cgoa-exam`, and `capa-exam`: **closed-book multiple choice**, not a live cluster like CKA or ICA.

Outline checked against the Linux Foundation [CNPA page](https://training.linuxfoundation.org/certification/certified-cloud-native-platform-engineering-associate-cnpa/), [CNCF CNPA](https://www.cncf.io/training/certification/cnpa/), the [CNCF Platforms White Paper](https://tag-app-delivery.cncf.io/whitepapers/platforms/), and the Platform Engineering Maturity Model on 2026-08-19.

CNPA is **vendor-neutral platform engineering**. It is not CKA (cluster admin), not CGOA (OpenGitOps only), not CAPA (Argo products). Tools (Kubernetes, GitOps engines, Backstage, Crossplane, OPA, OpenTelemetry) appear as **examples of capabilities**, not as product certifications. If two answers work, pick the one that treats the **platform as a product**: self-service, golden paths, least cognitive load, secure by default.

## CNPA vs Neighbour Exams

| Exam | CNPA overlap |
| --- | --- |
| **CGOA** | GitOps vocabulary (pull, reconcile). CNPA adds **why the platform offers GitOps** and env promotion. |
| **CAPA** | Argo as *an* implementation. CNPA will not ask Workflow DAG YAML. |
| **PCA** | Metrics/logs/traces as **platform capabilities** (OTel), not PromQL. |
| **CKS / KCSA** | PSS, NetworkPolicy, supply chain as **secure-by-default platform**. |
| **KCNA** | Kubernetes as the platform substrate. |

## Universal CNPA Reasoning Flow

```text
1. Who is the customer?
   Developers / other platform users  -> design for self-service
   The platform team drowning in tickets -> you failed the product test

2. Is the capability a golden path (paved, optional) or a mandate?
   Golden path = default easy way, escape hatch exists
   Ticket to the platform team for every namespace = anti-pattern

3. Is desired state declarative and reconciled?
   ClickOps / unique snowflake clusters -> not a platform
   CRD / Git / Crossplane / operator -> platform API

4. Is it secure and observable by default?
   App teams assembling OTel + NetworkPolicy from scratch -> platform gap

5. How would you know it worked?
   DORA + time-to-first-deploy + golden-path adoption + fewer platform tickets
   “We installed Backstage” is not a metric
```
