# CNPA Pitfalls

1. Treating CNPA as CKA (kubectl trivia).
2. Treating CNPA as CGOA (four sentences only) or CAPA (Argo YAML).
3. **Ticket ops** as “the platform.”
4. **Backstage = the platform.**
5. Golden path as a **prison** with no escape hatch.
6. Starting with 30 tools (**not** TVP).
7. Platform team **deploys every app** (ops silo).
8. ClickOps console as source of truth.
9. CI `kubectl` to prod.
10. Rebuild image per environment.
11. `:latest` as the artifact.
12. Ingress TLS thought to encrypt pod-to-pod.
13. Policy only in a PDF.
14. Zero exceptions forever → shadow IT.
15. cluster-admin for all app teams.
16. Plaintext secrets in Git.
17. Fork PR pipelines with write secrets.
18. Confusing CI with CD.
19. GitOps webhook confused with Argo Events.
20. CRD without a controller.
21. Leaky CRDs (all cloud fields).
22. One-shot Job called an operator.
23. Terraform laptop apply as “Kubernetes provisioning.”
24. Empty portal as DX success.
25. AI applying to cluster unreviewed.
26. DORA used to blame teams while the path is a queue.
27. Success = number of CNCF projects.
28. Observability optional on the golden path.
29. Mesh required in every answer (it is **an** mTLS option).
30. 90-minute timing — CNPA is **120**.
31. Skipping IDP/DORA because 8% — precise definitions are asked.
32. SPACE confused with DORA four keys.
33. MTTR improved only by “hire more heroes.”
34. Closed book: drill **which layer** + four DORA names.
