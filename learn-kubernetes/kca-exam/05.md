# 05. Helm Installation

**Domain:** Installation, Configuration, and Upgrades (18%)

## Concept Refresher

Supported install: **Helm chart** `kyverno/kyverno` into namespace **`kyverno`** (convention).

```bash
helm repo add kyverno https://kyverno.github.io/kyverno/
helm install kyverno kyverno/kyverno -n kyverno --create-namespace
```

Chart values control replica counts, resources, webhook failurePolicy, features (reports, cleanup), image registry, extra args.

**Not** a single static Pod. Several Deployments (admission, background, reports, cleanup).

Manifests-only install exists but Helm is the exam path.

Admission webhooks are created by the chart. Installing **without** waiting for the webhook can cause a race (`no endpoints`).

`helm upgrade` is the upgrade path (see `08.md`).
