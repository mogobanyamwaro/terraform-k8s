# 14. Validation Rules and Preconditions

**Domain:** Writing Policies (32%)

## Concept Refresher

**pattern** — overlay the object; missing required fields fail.

```yaml
validate:
  message: "privileged not allowed"
  pattern:
    spec:
      containers:
        - name: "*"
          securityContext:
            privileged: false
```

**deny** — JMESPath conditions (often clearer than wild overlays):

```yaml
validate:
  deny:
    conditions:
      any:
        - key: "{{ request.object.spec.containers[?image=='*:latest'] }}"
          operator: NotEquals
          value: []
```

**foreach** — iterate lists (containers, volumes).

**Anchors** (overlay):

| Anchor | Idea |
| --- | --- |
| `(field)` | If field exists, apply inner pattern |
| `=(field)` | Equality / optional-style (docs: conditional) |
| `X(field)` | Existence |
| `^(field)` | More a **mutate** add-if-not-present |
| `!*` / `!value` | Negation |
| `?*` | Must be present, any non-empty |

**Preconditions** — skip the rule unless true:

```yaml
preconditions:
  all:
    - key: "{{ request.operation }}"
      operator: Equals
      value: CREATE
```

Operators: Equals, NotEquals, In, AnyIn, AllIn, GreaterThan, Duration helpers, …
