# 08. High Availability and Upgrades

**Domain:** Installation, Configuration, and Upgrades (18%)

## Concept Refresher

**HA:** run **multiple replicas** of the **admission-controller** (often 3) with anti-affinity so a node loss doesn’t fail closed. PDB. Resources/requests so it isn’t OOM-killed.

Webhook `failurePolicy: Fail` + 0 ready pods = **cluster apply outage**. Production: replicas + PDB + fail-open only if you accept policy gaps.

Reports/background can scale separately; they are not on the user request path the same way.

**Upgrades:** `helm upgrade kyverno kyverno/kyverno -n kyverno` following the **release notes** (CRD conversions, new controllers). Don’t skip minor versions blindly. Backup ClusterPolicies first.

During upgrade, rolling restart of admission — brief webhook blips. `maxUnavailable: 0` / PDB helps.

Removing Kyverno: `helm uninstall` **does not** always delete CRDs/policies (Helm CRD caveat). Policies left behind are inert without webhooks.
