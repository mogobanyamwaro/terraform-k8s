# 11. `kyverno jp` and CLI Odds

**Domain:** Kyverno CLI (12%)

## Concept Refresher

**`kyverno jp`** evaluates **JMESPath** (the same family as policy variables `{{ … }}`).

```bash
kyverno jp query -i pod.yaml 'spec.containers[].image'
# or documented aliases: kyverno jp 'spec.containers[].image' -i pod.yaml
```

Use it to **debug** why a `key: "{{ request.object.spec... }}"` is empty.

Policies use JMESPath inside `{{ }}`. `jp` is the REPL for that language. It is **not** JSONPath from `kubectl get -o jsonpath` (similar idea, different syntax).

Other CLI: `kyverno version`, `kyverno docs`, `kyverno create` (scaffolds), OCI apply where documented.

Install reminder: CLI version should be **close** to cluster Kyverno.
