# 09. CLI Install and `apply`

**Domain:** Kyverno CLI (12%)

## Concept Refresher

Install: GitHub release binary, Homebrew, `kubectl krew install kyverno`, distro packages. CLI is **not** the in-cluster controllers.

**`kyverno apply`** evaluates policies against resource files (or a cluster) **without** requiring admission.

```bash
kyverno apply policy.yaml --resource pod.yaml
kyverno apply policy.yaml --resource ns/*.yaml
kyverno apply policy.yaml --cluster   # against live objects (needs kubeconfig)
```

Output: pass/fail per rule. `--policy-report` can emit a report YAML.

Shift-left: CI runs `apply` on PR manifests. Cluster still needs the same YAML applied as CRs to **enforce**.

`apply` does not persist ClusterPolicy unless you `kubectl apply` the policy.
