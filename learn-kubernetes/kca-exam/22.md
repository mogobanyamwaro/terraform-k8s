# 22. PolicyExceptions and Metrics

**Domain:** Policy Management (10%)

## Concept Refresher

**PolicyException** (`kyverno.io/v2`) — allow specific resources/users to **skip** named rules.

```yaml
apiVersion: kyverno.io/v2
kind: PolicyException
metadata:
  name: allow-pause
  namespace: prod
spec:
  exceptions:
    - policyName: require-team-label
      ruleNames: [check-team]
  match:
    any:
      - resources:
          kinds: [Pod]
          names: ["pause"]
```

Use for break-glass, migration, DaemonSet pause containers — **not** as a substitute for fixing policies. Exceptions can be namespaced.

**Metrics** — Kyverno exposes **Prometheus** metrics on controller `/metrics` (policy results, admission latency, rule counters). Chart can enable ServiceMonitor.

High-yield names conceptually: policy rule execution, admission requests, controller workqueue — exam: **metrics exist for SLOs**, scrape the controllers.

Don’t confuse Kyverno metrics with app RED. Don’t confuse PolicyException with webhook `failurePolicy` or `validationFailureActionOverrides`.
