# 18. Infrastructure Provisioning with Kubernetes

**Domain:** Platform APIs and Provisioning (12%)

## Concept Refresher

Provision **infra via Kubernetes APIs**, not only cloud consoles.

| Approach | What it provisions |
| --- | --- |
| **Cluster API (CAPI)** | Clusters/machines as CRs |
| **Crossplane** | Cloud resources via XR/XRD compositions |
| **ACK / Config Connector / Azure Service Operator** | Cloud APIs as K8s objects |
| **Operators** (RDS, Kafka) | Data services |
| Terraform **controllers** | HCL from Git, still a loop (map carefully vs Atlantis PR apply) |

**Why:** one control plane, GitOps, RBAC, same policy engine, self-service CRs.

**Not:** Terraform CLI on a laptop as the only process (works, weaker platform).

Compositions = golden path for “give me a bucket + IAM for my team.”
