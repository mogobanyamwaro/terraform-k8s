# 17. Reconciliation Loop and CRDs

**Domain:** Platform APIs and Provisioning (12%)

## Concept Refresher

Kubernetes is a **reconciliation** machine: controllers watch **desired** (spec) vs **actual** (status) and act.

**Custom Resource Definitions (CRDs)** extend the API. A `Team`, `Application`, or `Bucket` CR is a **self-service platform API**. Users `kubectl apply` (or GitOps) the CR; a controller does the toil (namespaces, IAM, DNS).

| Term | Meaning |
| --- | --- |
| CRD | Schema of the API |
| CR | An instance |
| spec | Desired |
| status | Observed, including conditions |
| finalizer | Cleanup before delete |

Bad API: leak 40 cloud fields. Good API: **job-to-be-done** (`size: small`, `team: payments`).
