# 08. Observability Fundamentals

**Domain:** Observability, Security, and Conformance (20%)

## Concept Refresher

**Observability:** infer internal state from **telemetry**. Pillars (exam list): **metrics, logs, traces, events**.

| Signal | Answers |
| --- | --- |
| Metrics | How much / how often (RED, USE, SLIs) |
| Logs | What happened, context |
| Traces | Where time went across services (`traceparent`) |
| Events | Discrete occurrences (K8s Warning, audit, deploy) |

**OpenTelemetry** is the vendor-neutral **instrumentation and transport**. Backends (Prometheus, Loki, Jaeger, Tempo, vendor) are **swappable**. The platform should run a **Collector** and inject SDKs/auto-instrumentation on the golden path.

Platform jobs:

- Default dashboards/SLOs for the path (not 50 unique stacks)
- Correlate deploy events with golden signals
- Cardinality and retention as a **product** (cost)

`up` vs business SLI: platform provides both infra and app recipes.
