# 11. Kubernetes Security Essentials

**Domain:** Observability, Security, and Conformance (20%)

## Concept Refresher

Platform-level K8s security (not a full CKS):

| Area | Platform default |
| --- | --- |
| RBAC / least privilege | Bound roles per tenancy; no cluster-admin for apps |
| Service accounts | Disable automount when unused; short tokens |
| Pod Security | Restricted PSS / equivalent Kyverno; drop ALL caps |
| Isolation | Namespaces, NetworkPolicy, optional gVisor/Kata |
| Secrets | External Secrets / CSI / Sealed; not plaintext Git |
| API | Audit logs, OIDC to the API, admission |
| Nodes | Patching, minimal OS — platform/SRE owned |
| Supply chain | Signed images, admission verify |

Multi-tenant **hardened defaults** beat optional “security extra” Helm values nobody enables.

Break-glass cluster-admin is **audited and rare**.

## Exam tips

- **Least privilege, Restricted PSS, no plaintext secrets, audit on.**
- Platform **owns** node/API hardening; apps consume it.
