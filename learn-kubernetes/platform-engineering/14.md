# 14. CI/CD Relationship Fundamentals

**Domain:** Continuous Delivery & Platform Engineering (16%)

## Concept Refresher

**CI ⊂ delivery**, but **CI ≠ CD**.

```text
  code  --CI-->  artifact (digest)  --CD/GitOps-->  environment
                     ^
              tests, sign, SBOM
```

| | CI | CD |
| --- | --- | --- |
| Question | Is this revision good? | Is it running in env X? |
| Trigger | Commit/PR | Git desired-state change, schedule, promote |
| Failure | Block merge | Block/roll back env; incident |
| Identity | Build SA | Reconcile SA |

**Continuous deployment** = CD without a human prod click (still Git review maybe). **Continuous delivery** = always releasable; prod may wait a button/flag.

Platform teams **own the relationship**: artifact contract (OCI, digest), env contract (overlays), and who is allowed to promote.

Confusing the two causes: CI with cluster-admin, or CD that rebuilds binaries.
