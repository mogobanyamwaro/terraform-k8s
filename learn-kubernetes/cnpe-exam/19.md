# 19. Diagnose and Remediate

**Domain:** Observability (20%) — incidents

## Question

Something is broken in `cnpe-19` (typical exam: ImagePullBackOff, CrashLoop, failed GitOps sync, denied by Kyverno, full quota, wrong selector). Restore the app `store` to Ready **without** deleting the namespace.

Work the loop: events → describe → logs → fix YAML → apply.

## Answer (playbook)

```bash
kubectl -n cnpe-19 get deploy,po,events --sort-by=.lastTimestamp
kubectl -n cnpe-19 describe pod -l app=store
kubectl -n cnpe-19 logs deploy/store --tail=50
```

| Symptom | Fix |
| --- | --- |
| ImagePullBackOff | Typo tag; set a pullable image |
| CrashLoop `OOMKilled` | Raise limit or cut memory leak; at least raise limit |
| `CreateContainerConfigError` secret | Create the Secret / fix envFrom |
| 0 replicas / HPA 0 | Fix HPA minReplicas |
| Argo OutOfSync + selfHeal fighting kubectl | Change **Git** or disable selfHeal per task |
| Kyverno block | Fix pod securityContext or policy exception if allowed |
| Quota exceeded | Delete orphans or raise quota as tasked |
| Service empty endpoints | Align labels |

If GitOps owns the object, patch the **source** the engine uses, not only live.

## Verify

```bash
kubectl -n cnpe-19 rollout status deploy/store --timeout=90s
kubectl -n cnpe-19 get po
```

## Exam tips

- `kubectl get events` first. Don’t restart `base`.
- For Argo: `argocd app get` / Application `status.conditions`.
- For Flux: `kubectl describe kustomization`.
