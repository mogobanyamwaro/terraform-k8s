# 16. ApplicationSet or App-of-Apps

**Domain:** Platform APIs (25%) — self-service at fleet scale

## Question

Argo CD: ApplicationSet `teams` using a **list** generator with elements `alpha` and `beta`. Each Application:

- name `app-{{name}}`
- namespace `cnpe-16-{{name}}`
- source the guestbook path (or the repo in the task)
- automated sync + CreateNamespace

## Answer

```yaml
apiVersion: argoproj.io/v1alpha1
kind: ApplicationSet
metadata:
  name: teams
  namespace: argocd
spec:
  generators:
  - list:
      elements:
      - name: alpha
      - name: beta
  template:
    metadata:
      name: 'app-{{name}}'
    spec:
      project: default
      source:
        repoURL: https://github.com/argoproj/argocd-example-apps
        targetRevision: HEAD
        path: guestbook
      destination:
        server: https://kubernetes.default.svc
        namespace: 'cnpe-16-{{name}}'
      syncPolicy:
        automated: {prune: true, selfHeal: true}
        syncOptions: [CreateNamespace=true]
```

App-of-Apps: a parent Application whose path is a folder of Application YAMLs. Flux equivalent: a root Kustomization that references child Kustomizations.

## Verify

```bash
kubectl -n argocd get applicationset,app
kubectl get ns | grep cnpe-16
```

## Exam tips

- Go template `{{name}}` must match generator keys.
- ApplicationSet controller must be running (`applicationset-controller` pod).
