# 15. Helm as a Platform Template

**Domain:** Platform APIs (25%) — automation frameworks

## Question

Package the golden-path app as Helm values. In `cnpe-15`, install chart from `/charts/app` or the URL in the task, release name `payments`, set `replicaCount=3`, `image.tag=1.2.3`.

If using Argo CD, Application source `helm.parameters` instead of `helm install`.

## Answer

```bash
kubectl create namespace cnpe-15
helm install payments /charts/app -n cnpe-15 \
  --set replicaCount=3 \
  --set image.tag=1.2.3
```

Argo CD:

```yaml
source:
  repoURL: ...
  path: charts/app
  helm:
    parameters:
    - {name: replicaCount, value: "3"}
    - {name: image.tag, value: "1.2.3"}
```

Kustomize overlay alternative: `kustomize edit set image` / `replicas`.

## Verify

```bash
helm -n cnpe-15 get values payments
kubectl -n cnpe-15 get deploy -o jsonpath='{.items[0].spec.replicas}'
```

## Exam tips

- Exam may forbid standing Helm releases and require **GitOps Helm**. Follow the task verb (`helm install` vs Application).
- `--dry-run` then apply if you must inspect.
