# 25. Kyverno (or Gatekeeper) Governance

**Domain:** Security (15%) — policy engines / admission

## Question

ClusterPolicy `require-non-root` **Enforce**: all Pods in namespace `cnpe-25` must have `spec.securityContext.runAsNonRoot: true` (or container securityContext). Mutate defaults if the task says **mutate**; otherwise validate.

Also deny `:latest` image tags in that namespace.

## Answer

```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata: {name: require-non-root}
spec:
  validationFailureAction: Enforce
  rules:
  - name: nonroot
    match:
      any:
      - resources:
          kinds: [Pod]
          namespaces: [cnpe-25]
    validate:
      message: runAsNonRoot required
      pattern:
        spec:
          securityContext:
            runAsNonRoot: true
---
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata: {name: disallow-latest}
spec:
  validationFailureAction: Enforce
  rules:
  - name: latest
    match:
      any:
      - resources:
          kinds: [Pod]
          namespaces: [cnpe-25]
    validate:
      message: ":latest not allowed"
      foreach:
      - list: request.object.spec.containers
        deny:
          conditions:
            any:
            - key: "{{ element.image }}"
              operator: Equals
              value: "*:latest"
```

`:latest` deny syntax varies — **copy from Kyverno docs** “disallow latest tag” sample. Gatekeeper equivalent: ConstraintTemplate + Constraint `K8sRequiredNonRoot`.

Mutate example: `patchesJson6902` / `mutate.overlay` to set `runAsNonRoot: true`.

## Verify

```bash
kubectl -n cnpe-25 run bad --image=nginx --restart=Never   # should fail
kubectl -n cnpe-25 run good --image=nginx:1.27 --restart=Never \
  --overrides='{"spec":{"securityContext":{"runAsNonRoot":true,"runAsUser":1000}}}'
```

nginx as non-root may still fail on filesystem — use `bitnami/nginx` if needed. Grader often only checks the **policy exists and blocks** a privileged pod.

## Exam tips

- `Audit` vs `Enforce` — task will say. Default to Enforce if it says “must”.
- Match **Pods** not only Deployments (controllers create pods).
- `validationFailureAction` at spec level (Kyverno v1).
