# 21. (Spare ops) GitOps Sync Failure

**Domain:** Observability (20%)

## Question

Application `broken` in Argo CD (or Flux Kustomization `broken`) is Degraded/Failed. Repo URL, path, or `destination.namespace` is wrong. Fix the GitOps object so sync **Succeeds** and the Deployment `web` exists in `cnpe-21`.

## Answer

```bash
kubectl -n argocd describe application broken
# status.conditions, operationState.message
```

Typical fixes: `targetRevision`, `path`, credentials Secret, `CreateNamespace=true`, AppProject `sourceRepos`, destination namespace typo.

Flux:

```bash
kubectl -n flux-system describe kustomization broken
flux reconcile kustomization broken --with-source
```

## Verify

```bash
kubectl -n cnpe-21 get deploy web
```

## Exam tips

- Read **status**, don’t rewrite from scratch.
- Auth errors: `git-credentials` / `ssh-credentials` Secret in flux-system or argocd.
