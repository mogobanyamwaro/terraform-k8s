# 07. Tekton CI Pipeline

**Domain:** GitOps and CD (25%) — CI/CD pipelines on Kubernetes

## Question

In `cnpe-07`, create a Pipeline `build-test` with two sequential Tasks:

1. Task `echo-src` — image `busybox:1.36`, command `echo`, args `building`
2. Task `echo-test` — image `busybox:1.36`, command `echo`, args `testing`

PipelineRun `build-test-run` should succeed. Both tasks as `Task` objects referenced by the Pipeline (not only inline), unless the task allows `pipeline.spec.tasks[].taskSpec`.

## Answer

```bash
kubectl create namespace cnpe-07
```

```yaml
apiVersion: tekton.dev/v1
kind: Task
metadata: {name: echo-src, namespace: cnpe-07}
spec:
  steps:
  - name: echo
    image: busybox:1.36
    command: [echo]
    args: [building]
---
apiVersion: tekton.dev/v1
kind: Task
metadata: {name: echo-test, namespace: cnpe-07}
spec:
  steps:
  - name: echo
    image: busybox:1.36
    command: [echo]
    args: [testing]
---
apiVersion: tekton.dev/v1
kind: Pipeline
metadata: {name: build-test, namespace: cnpe-07}
spec:
  tasks:
  - name: src
    taskRef: {name: echo-src}
  - name: test
    runAfter: [src]
    taskRef: {name: echo-test}
---
apiVersion: tekton.dev/v1
kind: PipelineRun
metadata: {name: build-test-run, namespace: cnpe-07}
spec:
  pipelineRef: {name: build-test}
```

A “real” exam item may add a `git-clone` catalog task and `kaniko`/`buildah`. Copy those from Quick Reference; **pin** the catalog Task version.

```bash

```

## Exam tips

- API group `tekton.dev/v1` (not alpha) on current Tekton.
- `runAfter` for sequence. Missing SA for git → describe PipelineRun.
