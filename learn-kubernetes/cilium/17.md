# 17. Cilium CLI: Install, Status, Connectivity Test

**Domain:** Installation and Configuration (10%)

## Concept Refresher

**Cilium CLI** (`cilium`) is the exam’s installation tool of record (Helm is also valid in production).

```bash
cilium install
cilium install --version 1.17.4 --set kubeProxyReplacement=true
cilium status
cilium status --wait
cilium connectivity test
cilium uninstall
cilium version
cilium hubble enable
cilium hubble port-forward
```

### Install requirements (conceptual)

- Linux kernel new enough for the Cilium version’s eBPF features
- Privileged agent (host network, BPF mounts, capabilities)
- Compatible CNI: **replace** existing CNI, do not stack blindly
- For kube-proxy replacement: disable kube-proxy, kernel support

### connectivity test

Creates test namespaces/pods and verifies:

- Pod-to-pod
- Service ClusterIP / NodePort
- NetworkPolicy allow/deny
- Optional Hubble, encryption, Cluster Mesh scenarios depending on flags

It is the **health exam** after install. Failures point at datapath, policy, DNS, or kube-proxy issues.

### Helm vs CLI

CLI wraps Helm charts internally in many versions. `helm install cilium cilium/cilium -n kube-system` is equivalent in spirit. Exam: CLI verbs above.
