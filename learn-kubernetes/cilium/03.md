# 03. IP Address Management (IPAM)

**Domain:** Architecture (20%)

## Concept Refresher

Every pod needs an IP. Cilium IPAM mode decides **who allocates it and from where**.

| Mode | Who allocates | Typical environment |
| --- | --- | --- |
| **cluster-pool** (default on many self-managed installs) | **cilium-operator** hands **podCIDRs per node** from a cluster pool; agent assigns IPs from the node’s pool | kind, bare metal, most labs |
| **kubernetes** | Uses **Node.spec.podCIDR** from Kubernetes (controller-manager `--allocate-node-cidrs`) | Clusters that already split CIDRs per node |
| **eni** | AWS ENI / secondary IPs | EKS / AWS |
| **azure** | Azure IPAM | AKS |
| **alibabacloud** | Alibaba ENI-style | ACK |
| **delegated** | External plugin | Special CNI chaining |

### cluster-pool

Helm/CLI sets something like:

```text
ipam.mode=cluster-pool
clusterPoolIPv4PodCIDRList=10.0.0.0/8
clusterPoolIPv4MaskSize=24
```

Operator carves `/24` (example) per node. Agent assigns pod IPs from that carve. **Do not overlap** with node IPs, Service CIDR, or another cluster (Cluster Mesh).

### kubernetes mode

Requires the Kubernetes controller manager to allocate `podCIDR` on each Node. Cilium does not invent the per-node range; it uses it.

### Cloud ENI modes

Pods get **VPC-routable** IPs from elastic network interfaces. That often pairs with **native routing** (no VXLAN) because the cloud network already knows the IPs.

### IPv6 / dual stack

Cilium supports IPv4, IPv6, dual stack. Exam: know it exists; pools are configured per family.

### Exhaustion

If a node’s pool is empty, pods stay `ContainerCreating` with CNI IPAM errors. Fix: enlarge mask/pool, add nodes, or free leaked IPs (operator GC).

## Hands-on

```bash
cilium status | grep -i ipam
kubectl -n kube-system exec ds/cilium -- cilium-dbg ip list | head
kubectl get nodes -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.spec.podCIDR}{"\n"}{end}'
```

## Exam tips

- **cluster-pool → operator.** **kubernetes → Node podCIDR.** **eni/azure → cloud NICs.**
- Mesh/multi-cluster: **non-overlapping pod CIDRs**.
- IPAM is architecture, not BGP — BGP may *advertise* those CIDRs later (`24.md`).
