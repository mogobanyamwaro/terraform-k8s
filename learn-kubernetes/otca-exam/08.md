# 08. Tracing Signal

**Domain:** The OpenTelemetry API and SDK (46%)

## Concept Refresher

Get a `Tracer` from `TracerProvider`. `tracer.start_span` / `start_as_current_span` creates a **span**. End it (or use a `with`/try-with-resources). Unended spans leak.

**Current context** holds the parent. Child spans attach automatically if you start while a span is current. Across threads/async, **context must be attached** or you get new roots (broken traces).

**Span kind**

| Kind | Use |
| --- | --- |
| INTERNAL | In-process work |
| SERVER | Inbound RPC/HTTP |
| CLIENT | Outbound RPC/HTTP |
| PRODUCER | Send to queue |
| CONSUMER | Receive from queue |

**Status:** leave UNSET on success (many HTTP 2xx stay UNSET); set ERROR on failures. OK exists but is optional.

**Record exception:** `span.record_exception(e)` + status ERROR.

**Attributes:** add with conventions (`http.response.status_code`).

**Active span vs recording:** if not sampled, the span may be non-recording (API still safe).

- Kind describes *role*, not HTTP status.
