# 07. SDK Configuration

**Domain:** The OpenTelemetry API and SDK (46%)

## Concept Refresher

Two styles: **programmatic** (code) and **environment / file** (`OTEL_*`, sometimes `sdk-config.yaml` in newer SDKs). Env is the exam-friendly operator path.

**High-yield variables**

| Variable | Role |
| --- | --- |
| `OTEL_SERVICE_NAME` | Resource `service.name` |
| `OTEL_RESOURCE_ATTRIBUTES` | `key=value,key2=value2` |
| `OTEL_TRACES_EXPORTER` | `otlp`, `console`, `none`, … |
| `OTEL_METRICS_EXPORTER` | `otlp`, `prometheus`, `console`, `none` |
| `OTEL_LOGS_EXPORTER` | `otlp`, `console`, `none` |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | Collector/backend base |
| `OTEL_EXPORTER_OTLP_PROTOCOL` | `grpc`, `http/protobuf`, `http/json` |
| `OTEL_EXPORTER_OTLP_HEADERS` | Auth metadata |
| `OTEL_TRACES_SAMPLER` | `always_on`, `always_off`, `traceidratio`, `parentbased_*` |
| `OTEL_TRACES_SAMPLER_ARG` | Ratio e.g. `0.1` |
| `OTEL_PROPAGATORS` | `tracecontext,baggage` (comma list) |
| `OTEL_SDK_DISABLED` | `true` → no-op |
| `OTEL_LOG_LEVEL` | SDK diagnostic logs |

OTLP default ports: **4317 gRPC**, **4318 HTTP**. If endpoint is `http://collector:4318`, protocol should match.

Signal-specific: `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` overrides the general endpoint.

Programmatic config **wins or merges** depending on language; exam: env is how operators configure agents.

## Hands-on

Export with `OTEL_TRACES_EXPORTER=console`, then switch to OTLP toward the lab Collector. Change `OTEL_SERVICE_NAME`.

## Exam tips

- **4317 gRPC / 4318 HTTP.**
- Sampler env is **head** sampling in the SDK, not Collector tail sampling.
