# 19. Transforming Data

**Domain:** The OpenTelemetry Collector (26%)

## Concept Refresher

Processors **mutate** telemetry before export.

| Processor | Job |
| --- | --- |
| `attributes` | Insert/update/delete/hash attributes |
| `resource` | Resource attributes |
| `filter` | Drop spans/metrics/logs by rules |
| `span` | Rename spans, extract from attributes |
| `transform` | **OTTL** statements |
| `redaction` / `attributes` hash | PII |
| `k8sattributes` | Enrich from Kubernetes API |
| `resourcedetection` | cloud/host resource |
| `probabilistic_sampler` | Head-like sampling in Collector (not tail) |

**OTTL** (OpenTelemetry Transformation Language): `set`, `delete_key`, `replace_pattern`, `route` — scoped to `span`, `resource`, `log`, `metric`, `datapoint`.

Example:

```yaml
transform:
  trace_statements:
    - context: span
      statements:
        - set(span.attributes["env"], resource.attributes["deployment.environment"])
```

Prefer conventions; transform to **align** incoming vendor/old names to semantic conventions.

Don’t drop `service.name`. Hash `user.email` rather than shipping it.
