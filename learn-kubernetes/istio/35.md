# 35. Break-and-Fix Drills

Work these against a snapshot of your lab. Sabotage, then repair without looking at the solution. Time each drill (target 8 minutes).

---

## Drill 1 — Ghost subset

**Sabotage:** VirtualService `reviews` routes 100% to subset `canary`. No such DestinationRule subset.

**Symptom:** productpage reviews section errors, 503.

**Fix:** Add subset `canary` matching real pods **or** point the VS at `v1`. Analyze should go clean.

---

## Drill 2 — Gateway selector typo

**Sabotage:** Gateway `selector: { istio: ingress }` (wrong). VS bound to it.

**Symptom:** curl to ingress 404, `pc listener` on ingressgateway has no server for that host.

**Fix:** `istio: ingressgateway`. Confirm `kubectl -n istio-system get pod -l istio=ingressgateway`.

---

## Drill 3 — Host mismatch

**Sabotage:** Gateway hosts `shop.example.com`, VS hosts `www.shop.example.com`.

**Symptom:** 404 from gateway.

**Fix:** Make hosts intersect. Often both should be `shop.example.com`.

---

## Drill 4 — STRICT leftover

**Sabotage:** PeerAuthentication STRICT in `demo`. Task needs `nomesh` client to call httpbin.

**Symptom:** unmeshed curl fails; meshed works.

**Fix:** PERMISSIVE or delete PA. If the real task was "enforce mTLS for mesh clients" keep STRICT and **do not** use nomesh as the tester.

---

## Drill 5 — JWT without authz

**Sabotage:** RequestAuthentication only. Examiner tests with no token and expects 403.

**Symptom:** 200 without token.

**Fix:** ALLOW AuthorizationPolicy `requestPrincipals: ["*"]`.

---

## Drill 6 — ALLOW default deny surprise

**Sabotage:** ALLOW GET only on httpbin. App probes on `/` POST health fail, pod not Ready.

**Fix:** Extra rule for probe paths/methods, or probe on a DISABLE mTLS port (`25.md` tips).

---

## Drill 7 — Sidecar dropped istiod

**Sabotage:** Sidecar egress `demo/*` only.

**Symptom:** STALE / cert errors / new pods not Ready.

**Fix:** Add `istio-system/*`. Delete overly tight Sidecar if not required.

---

## Drill 8 — REGISTRY_ONLY blackhole

**Sabotage:** Mesh or Sidecar `REGISTRY_ONLY`. App needs `httpbin.org`.

**Symptom:** curl external host fails, `BlackHoleCluster` in pc.

**Fix:** ServiceEntry for that host. Do not flip back to ALLOW_ANY if the task required a registry.

---

## Drill 9 — Egress hop incomplete

**Sabotage:** ServiceEntry + Gateway, no VS match for `mesh` rewriting to egress Service.

**Symptom:** traffic still passthrough (egress logs empty).

**Fix:** Four-object recipe (`15.md`). DR mTLS to egressgateway FQDN.

---

## Drill 10 — Circuit breaker too small

**Sabotage:** `http1MaxPendingRequests: 0` or `maxConnections: 0`.

**Symptom:** every request 503 UO.

**Fix:** Raise pool or remove the DR trafficPolicy.

---

## Drill 11 — Fault + timeout

**Sabotage:** delay 5s, timeout 2s. Task wanted 5s delay visible to the app.

**Symptom:** 504, upstream unused.

**Fix:** timeout > delay, or remove timeout.

---

## Drill 12 — Wrong gateway on VS

**Sabotage:** VS `gateways: [mesh]` only, task is ingress.

**Symptom:** in-mesh curl works, `curl $INGRESS` 404.

**Fix:** `gateways: [bookinfo-gateway]` or both.

---

## Drill 13 — Secret namespace

**Sabotage:** TLS Secret in `demo`, ingress in `istio-system`.

**Symptom:** HTTPS handshake error, gateway log missing cert.

**Fix:** Create `credentialName` Secret in `istio-system`.

---

## Drill 14 — Injection conflict

**Sabotage:** ns has `istio-injection=enabled` and `istio.io/rev=1-24-0` but only 1.26 istiod exists.

**Symptom:** 1/1 pods, no sidecar.

**Fix:** Remove the bad label, restart workloads (`07.md`, `32.md`).

---

## Drill 15 — Ambient L7 no waypoint

**Sabotage:** Ambient ns, VirtualService timeout 1s, no waypoint.

**Symptom:** `/delay/5` still succeeds (no timeout).

**Fix:** Install waypoint, label service `istio.io/use-waypoint`, retest (`05.md`, `36.md`).

---

## Drill 16 — Port protocol

**Sabotage:** Service port name `tcp-web` for HTTP app, HTTP VS + AuthorizationPolicy paths.

**Symptom:** path rules ignored or NR.

**Fix:** Name `http` or set `appProtocol: http`.

---

## Drill 17 — Weight without subset DR

**Sabotage:** 80/20 v1/v2, DestinationRule only defines v1.

**Symptom:** 20% 503.

**Fix:** Define v2 subset with correct labels.

---

## Drill 18 — Authorization on the wrong workload

**Sabotage:** Policy selected `app: sleep` (client) instead of `httpbin`.

**Symptom:** policy "does nothing".

**Fix:** Authorization is inbound. Select the **server**.

---

## How to practise

```bash
# snapshot
kind export kubeconfig --name istio-lab
# after a drill, rebuild
~/istio-lab-build.sh     # from Lab-Setup.md
```

Write the flag you saw (`NR`, `UH`, `UO`, `UT`, `UF`) before you apply the fix. That habit is the exam.
