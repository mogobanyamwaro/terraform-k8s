# 34. Observability: Metrics, Access Logs, Tracing, Kiali

## Concept Refresher

Observability is not a top-level ICA domain after August 2025, but troubleshooting tasks assume you can turn on access logs, scrape Envoy metrics, and read traces. The **Telemetry API** is the current switch.

```yaml
apiVersion: telemetry.istio.io/v1
kind: Telemetry
metadata:
  name: mesh-default
  namespace: istio-system
spec:
  accessLogging:
    - providers:
        - name: envoy
  tracing:
    - providers:
        - name: otel
      randomSamplingPercentage: 100
  metrics:
    - providers:
        - name: prometheus
```

Namespace Telemetry overrides mesh. Workload `selector` / `targetRef` overrides namespace.

### Metrics

Sidecar listens on **15020** `/stats/prometheus` (merged). Raw Envoy is **15090**.

Standard metrics (names slightly vary):

```text
istio_requests_total
istio_request_duration_milliseconds
istio_request_bytes / istio_response_bytes
istio_tcp_connections_opened_total
```

Labels: `source_app`, `destination_service`, `response_code`, `request_protocol`, `reporter` (`source`|`destination`).

```bash
kubectl -n demo exec deploy/httpbin -c istio-proxy -- \
  curl -s 127.0.0.1:15020/stats/prometheus | grep istio_requests_total | head
```

Addons from `samples/addons`: Prometheus, Grafana, Kiali, Jaeger.

```bash
kubectl apply -f samples/addons
istioctl dashboard kiali     # not in the exam browser the same way; use kubectl port-forward in the lab
```

### Access logs

`demo` profile: logs on. `default` profile: often off. Enable with Telemetry as above or meshConfig `accessLogFile: /dev/stdout`.

JSON format is easier to grep for `response_flags` and `upstream_cluster`.

### Tracing

Need a provider (Jaeger / Zipkin / OpenTelemetry). MeshConfig `extensionProviders` + Telemetry `tracing`. Sampling 100% in lab, 1% in production.

B3 / W3C headers propagate automatically through Envoy. Apps that start new HTTP clients **without** copying headers break the trace. ICA may ask you to enable tracing, not to instrument an app.

### Kiali

Needs Prometheus. Graph = telemetry, not config. Empty graph means metrics/Telemetry not flowing, not necessarily broken routing.

## Tasks

1. Enable Envoy access logs mesh-wide via Telemetry.
2. Enable 100% tracing to the Jaeger provider if addons are installed.
3. From `istio_requests_total`, confirm `sleep` → `httpbin` returns 200.
4. Open (lab) Kiali and find the Bookinfo graph. On the exam, use metrics/logs instead if no dashboard.

## Solutions

### 1. Access logs

```yaml
apiVersion: telemetry.istio.io/v1
kind: Telemetry
metadata:
  name: access-logs
  namespace: istio-system
spec:
  accessLogging:
    - providers:
        - name: envoy
```

Provider name `envoy` is built-in. Confirm:

```bash
kubectl -n demo logs deploy/sleep -c istio-proxy --tail=1
```

### 2. Tracing

```yaml
apiVersion: telemetry.istio.io/v1
kind: Telemetry
metadata:
  name: traces
  namespace: istio-system
spec:
  tracing:
    - randomSamplingPercentage: 100
```

If a named provider is required:

```yaml
    - providers:
        - name: jaeger
      randomSamplingPercentage: 100
```

Install addons first so the provider exists in MeshConfig.

### 3. Metrics

```bash
kubectl -n demo exec deploy/sleep -c sleep -- curl -sS -o /dev/null http://httpbin:8000/get
kubectl -n demo exec deploy/sleep -c istio-proxy -- \
  curl -s 127.0.0.1:15020/stats/prometheus \
  | grep 'istio_requests_total{.*destination_service="httpbin.demo.svc.cluster.local"'
```

### 4. Kiali (lab)

```bash
kubectl -n istio-system port-forward svc/kiali 20001:20001
```

Exam environment may not include Kiali. Do not depend on it.

## Verify

```bash
kubectl get telemetry -A
kubectl -n istio-system get po | grep -E 'prometheus|jaeger|kiali|grafana'
```

## Exam Tips

- **Telemetry API in `istio-system` named mesh-wide** is the modern answer, not `istioctl install --set meshConfig.accessLogFile` unless the cluster is old-style.
- Metrics on 15020. Do not confuse with app `/metrics`.
- Empty `istio_requests_total` between two workloads: no traffic, or they are not meshed, or you grepped the wrong pod (source vs destination reporter).
- Docs: [Telemetry API](https://istio.io/docs/tasks/observability/telemetry/) and [Metrics](https://istio.io/docs/reference/config/telemetry/).
