# 03. Cost and Right-Sizing

**Domain:** Architecture (15%) — Cost management

## Question

Platform team wants waste visible.

1. Label namespace `cnpe-03` with `opencost=true` (or the label the task names).
2. Deployment `hungry` in that namespace: 1 replica, requests `cpu: 2` `memory: 4Gi` but the container is `nginx` doing nothing — then **right-size** requests to `100m` / `128Mi` and limits `200m` / `256Mi`.
3. If OpenCost is installed, open its UI or query the recommended request (Quick Reference). If not, still right-size from `kubectl top` if metrics-server exists.
4. Add annotation `platform.example.com/cost-center=payments` on the namespace.

## Answer

```bash
kubectl create namespace cnpe-03
kubectl label ns cnpe-03 opencost=true
kubectl annotate ns cnpe-03 platform.example.com/cost-center=payments
```

Fix the Deployment:

```bash
kubectl -n cnpe-03 set resources deploy hungry \
  --requests=cpu=100m,memory=128Mi \
  --limits=cpu=200m,memory=256Mi
```

OpenCost (if present):

```bash
kubectl -n opencost port-forward svc/opencost 9003:9003
# UI / API per Quick Reference; filter namespace cnpe-03
```

## Verify

```bash
kubectl -n cnpe-03 get deploy hungry -o jsonpath='{.spec.template.spec.containers[0].resources}'
kubectl get ns cnpe-03 --show-labels
kubectl get ns cnpe-03 -o jsonpath='{.metadata.annotations}'
```

## Exam tips

- Cost tasks are often **label + right-size**, not a full FinOps thesis.
- Requests ≫ usage is the smell. Copy `kubectl top pod` into new requests with a small headroom.
- OpenCost docs will be in Quick Reference if the binary/UI is in the env.
