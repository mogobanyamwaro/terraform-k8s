# 20. Platform Efficiency Metrics

**Domain:** Observability (20%) — deployment metrics / performance

## Question

In `cnpe-20`, Deployment `slow` has no resources and 1 replica. Make it platform-sane:

1. Requests/limits `100m/128Mi` and `200m/256Mi`.
2. HPA CPU 60%, min 2 max 6.
3. PodDisruptionBudget `minAvailable: 1`.
4. If Prometheus is up, confirm `kube_deployment_status_replicas` (or `kube-state-metrics`) is scraped — fix ServiceMonitor labels if missing.

Optional: record a Grafana note / ConfigMap `slo` with `availability: "99.9"` if the task wants an SLO object.

## Answer

```bash
kubectl -n cnpe-20 set resources deploy slow \
  --requests=cpu=100m,memory=128Mi --limits=cpu=200m,memory=256Mi
```

HPA + PDB YAML as in `02.md` / kubernetes.io PDB example.

```yaml
apiVersion: policy/v1
kind: PodDisruptionBudget
metadata: {name: slow, namespace: cnpe-20}
spec:
  minAvailable: 1
  selector: {matchLabels: {app: slow}}
```

## Verify

```bash
kubectl -n cnpe-20 get deploy,hpa,pdb slow
```

## Exam tips

- Efficiency = **right-size + autoscale + PDB**, not a DORA essay (that was CNPA).
- kube-state-metrics must be running for deploy metrics.
