# 05. Flux GitOps Application

**Domain:** GitOps and CD (25%)

## Question

Flux is installed. Reconcile app `podinfo` in namespace `cnpe-05`:

- `GitRepository` `podinfo` in `flux-system`, URL `https://github.com/stefanprodan/podinfo`, branch `master`, interval **1m**.
- `Kustomization` `podinfo` in `flux-system`, path `/kustomize`, targetNamespace `cnpe-05`, interval **2m**, `prune: true`.

Create the namespace. Wait until a Deployment exists in `cnpe-05`.

## Answer

```bash
kubectl create namespace cnpe-05
```

```yaml
apiVersion: source.toolkit.fluxcd.io/v1
kind: GitRepository
metadata:
  name: podinfo
  namespace: flux-system
spec:
  interval: 1m
  url: https://github.com/stefanprodan/podinfo
  ref: {branch: master}
---
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: podinfo
  namespace: flux-system
spec:
  interval: 2m
  prune: true
  targetNamespace: cnpe-05
  sourceRef:
    kind: GitRepository
    name: podinfo
  path: ./kustomize
```

```bash
flux reconcile source git podinfo -n flux-system
flux reconcile kustomization podinfo -n flux-system
```

If the exam Git is a **local** repo path, use that URL from the task. Copy API versions from Quick Reference — they change.

## Verify

```bash
kubectl -n flux-system get gitrepository,kustomization
kubectl -n cnpe-05 get deploy
```

## Exam tips

- `sourceRef` namespace defaults to the Kustomization’s namespace.
- `flux get all` / `kubectl describe kustomization` for errors (auth, path).
- Webhook is optional; interval is enough.
