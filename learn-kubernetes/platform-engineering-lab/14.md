# 14. Use an Operator (cert-manager)

**Domain:** Platform APIs (25%) — operators

## Question

cert-manager is installed. In `cnpe-14`:

1. Self-signed `ClusterIssuer` or `Issuer` `platform-ca` (selfSigned).
2. `Certificate` `web-tls` for DNS name `web.cnpe-14.svc`, secret `web-tls`, duration 2160h, issuerRef that Issuer.

If the task uses a different operator (CloudNativePG, RabbitMQ), same pattern: **create the CR, wait Ready**.

## Answer

```bash
kubectl create namespace cnpe-14
```

```yaml
apiVersion: cert-manager.io/v1
kind: Issuer
metadata: {name: platform-ca, namespace: cnpe-14}
spec:
  selfSigned: {}
---
apiVersion: cert-manager.io/v1
kind: Certificate
metadata: {name: web-tls, namespace: cnpe-14}
spec:
  secretName: web-tls
  duration: 2160h
  dnsNames: [web.cnpe-14.svc]
  issuerRef:
    name: platform-ca
    kind: Issuer
```

```bash
kubectl -n cnpe-14 wait certificate/web-tls --for=condition=Ready --timeout=90s
kubectl -n cnpe-14 get secret web-tls
```

## Verify

```bash
kubectl -n cnpe-14 get issuer,certificate,secret web-tls
kubectl -n cnpe-14 describe certificate web-tls
```

## Exam tips

- Operator tasks = apply the **documented CR**, not install the operator (usually already there).
- `describe` the CR — conditions tell you the miss (issuer not found).
- `kubectl get crd | grep cert` to find GVK.
