# 04. Multi-Tenancy Resource Usage

**Domain:** Architecture (15%)

## Question

Onboard team `payments` in namespace `cnpe-04`:

1. ResourceQuota `team-quota`: requests.cpu **2**, requests.memory **2Gi**, limits.cpu **4**, limits.memory **4Gi**, pods **20**, count/services **10**.
2. LimitRange `team-defaults`: container default request `100m`/`128Mi`, default limit `200m`/`256Mi`, max limit cpu `1` memory `1Gi`.
3. Pod Security `restricted` on the namespace (`pod-security.kubernetes.io/enforce: restricted`).
4. Role `dev` in the namespace: get/list/watch/create/update/patch/delete on pods, services, deployments. Bind to group `payments-devs`.

## Answer

```bash
kubectl create namespace cnpe-04
kubectl label ns cnpe-04 \
  pod-security.kubernetes.io/enforce=restricted \
  pod-security.kubernetes.io/enforce-version=latest
```

```yaml
apiVersion: v1
kind: ResourceQuota
metadata: {name: team-quota, namespace: cnpe-04}
spec:
  hard:
    requests.cpu: "2"
    requests.memory: 2Gi
    limits.cpu: "4"
    limits.memory: 4Gi
    pods: "20"
    services: "10"
---
apiVersion: v1
kind: LimitRange
metadata: {name: team-defaults, namespace: cnpe-04}
spec:
  limits:
  - type: Container
    default: {cpu: 200m, memory: 256Mi}
    defaultRequest: {cpu: 100m, memory: 128Mi}
    max: {cpu: "1", memory: 1Gi}
---
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata: {name: dev, namespace: cnpe-04}
rules:
- apiGroups: ["", "apps"]
  resources: ["pods", "services", "deployments"]
  verbs: ["get", "list", "watch", "create", "update", "patch", "delete"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata: {name: payments-devs, namespace: cnpe-04}
subjects:
- kind: Group
  name: payments-devs
  apiGroup: rbac.authorization.k8s.io
roleRef:
  kind: Role
  name: dev
  apiGroup: rbac.authorization.k8s.io
```

A `nginx` pod without securityContext will **fail** restricted PSS. That is intended. Platform golden path would set `runAsNonRoot` — see `22.md`.

## Verify

```bash
kubectl -n cnpe-04 get quota,limitrange,role,rolebinding
kubectl auth can-i create deployments -n cnpe-04 --as-group=payments-devs --as=u
```

## Exam tips

- Quota without LimitRange → pods with no requests may be **rejected** or not count as you expect. Set both.
- PSS `restricted` + default nginx = fail. Read the event.
