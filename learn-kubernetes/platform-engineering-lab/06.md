# 06. Argo CD Application

**Domain:** GitOps and CD (25%)

## Question

Argo CD is in `argocd`. Create Application `guestbook` that:

- project `default`
- repo `https://github.com/argoproj/argocd-example-apps`
- path `guestbook`
- revision `HEAD` or `master`
- destination in-cluster, namespace `cnpe-06`
- automated sync, **prune** and **selfHeal** true
- `CreateNamespace=true`

## Answer

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: guestbook
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/argoproj/argocd-example-apps
    targetRevision: HEAD
    path: guestbook
  destination:
    server: https://kubernetes.default.svc
    namespace: cnpe-06
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
    - CreateNamespace=true
```

```bash
kubectl apply -f app.yaml
# or: argocd app create ... if CLI is installed
argocd app wait guestbook --health --timeout 120
```

Helm variant: `chart`, `helm.valueFiles` — copy from Quick Reference if the task is a chart.

## Verify

```bash
kubectl -n argocd get application guestbook -o yaml | yq '.status.sync.status,.status.health.status'
kubectl -n cnpe-06 get deploy
```

## Exam tips

- Application CR lives in **argocd**, resources in **destination.namespace**.
- Synced ≠ Healthy. Wait or fix image pull.
- `argocd app get guestbook` if CLI exists.
