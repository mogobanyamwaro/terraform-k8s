# 02. Storage and Compute Defaults

**Domain:** Architecture (15%)

## Question

In `cnpe-02`, create:

1. StorageClass `cnpe-fast` using the cluster’s default provisioner (copy from `kubectl get sc`) with `reclaimPolicy: Delete` and `volumeBindingMode: WaitForFirstConsumer`.
2. PVC `app-data`, 2Gi, RWO, that StorageClass.
3. Deployment `app`, 2 replicas, image `nginx:1.27`, mounts the PVC at `/data`, requests `cpu: 100m` `memory: 128Mi`, limits `cpu: 200m` `memory: 256Mi`.
4. HorizontalPodAutoscaler `app` targeting the Deployment, CPU **70%**, min 2 max 5.

## Answer

```bash
kubectl create namespace cnpe-02
kubectl get sc
```

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: cnpe-fast
provisioner: rancher.io/local-path   # CHANGE to your default sc provisioner
reclaimPolicy: Delete
volumeBindingMode: WaitForFirstConsumer
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: app-data
  namespace: cnpe-02
spec:
  accessModes: [ReadWriteOnce]
  storageClassName: cnpe-fast
  resources:
    requests:
      storage: 2Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: app
  namespace: cnpe-02
spec:
  replicas: 2
  selector:
    matchLabels: {app: app}
  template:
    metadata:
      labels: {app: app}
    spec:
      containers:
      - name: nginx
        image: nginx:1.27
        resources:
          requests: {cpu: 100m, memory: 128Mi}
          limits: {cpu: 200m, memory: 256Mi}
        volumeMounts:
        - name: data
          mountPath: /data
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: app-data
---
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: app
  namespace: cnpe-02
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: app
  minReplicas: 2
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70
```

On kind, local-path may already exist — reuse it if the task says “use the default StorageClass” instead of creating one.

## Verify

```bash
kubectl -n cnpe-02 get deploy,pvc,hpa app
kubectl -n cnpe-02 describe pod -l app=app | grep -A2 Limits
```

## Exam tips

- HPA needs metrics-server. If HPA is `unknown`, that is an ops task later — still create the object.
- `WaitForFirstConsumer` is the usual platform default for topology.
