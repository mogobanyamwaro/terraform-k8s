## Part A: Networking Fundamentals for Administrators

### 3.1 The OSI Model & Linux Networking Stack

Understanding how Linux handles networking helps you troubleshoot at the right layer.

```
┌─────────────────────────────────────────────────────────────┐
│ Layer 7: Application    │ HTTP, SSH, DNS, Nginx, MySQL    │
├─────────────────────────────────────────────────────────────┤
│ Layer 4: Transport      │ TCP, UDP (ports, sockets)        │
├─────────────────────────────────────────────────────────────┤
│ Layer 3: Network        │ IP, ICMP (routing, iptables)     │
├─────────────────────────────────────────────────────────────┤
│ Layer 2: Data Link      │ Ethernet, ARP (MAC addresses)    │
├─────────────────────────────────────────────────────────────┤
│ Layer 1: Physical       │ Network cards, cables, WiFi      │
└─────────────────────────────────────────────────────────────┘
```

**📝 Hands-On: View Your Network Stack**

```bash
# View network interfaces (Layer 1-2)
ip link show
ip addr show

# View ARP table (Layer 2 mapping to Layer 3)
ip neigh show
arp -n

# View routing table (Layer 3)
ip route show
route -n

# View active connections (Layer 4)
ss -tulpn
netstat -tulpn

# View socket statistics with details
ss -tulpn -o
```

### 3.2 Network Interface Configuration

#### Understanding Interface Names

Modern Linux uses predictable interface names:

- `eth0`, `eth1` - Traditional Ethernet
- `ens33`, `ens192` - PCI Express slots
- `enp0s3` - PCI bus/slot
- `wlp2s0` - Wireless

```bash
# List all network interfaces
ip link show
ls /sys/class/net/

# Get detailed interface information
ethtool eth0  # If eth0 exists
ip -s link show  # Statistics

# Find your interface name (usually something like enp0s3 or ens33)
ip link show | grep -v lo | grep -E "^[0-9]+:"
```

#### Netplan Configuration (Ubuntu)

```bash
# Find your netplan configuration
ls /etc/netplan/
cat /etc/netplan/*.yaml

# Common netplan configurations:

# DHCP Configuration
cat > /tmp/01-netcfg.yaml << 'EOF'
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: true
      dhcp6: false
EOF

# Static IP Configuration
cat > /tmp/01-netcfg-static.yaml << 'EOF'
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
        search:
          - example.com
EOF

# Apply configuration
sudo cp /tmp/01-netcfg-static.yaml /etc/netplan/01-netcfg.yaml
sudo netplan try  # Test configuration, auto-reverts if connection lost
sudo netplan apply

# Verify
ip addr show
```

**🔴 RHEL Note:** RHEL uses NetworkManager and `nmcli` instead of netplan:

```bash
# RHEL equivalent:
nmcli connection show
nmcli connection modify eth0 ipv4.addresses 192.168.1.100/24
nmcli connection modify eth0 ipv4.gateway 192.168.1.1
nmcli connection modify eth0 ipv4.dns "8.8.8.8 1.1.1.1"
nmcli connection modify eth0 ipv4.method manual
nmcli connection up eth0
```

### 3.3 Advanced Networking Commands

#### IP Command Mastery

```bash
# Add/remove IP addresses
sudo ip addr add 192.168.100.10/24 dev eth0
sudo ip addr del 192.168.100.10/24 dev eth0

# Add secondary IP (IP aliasing)
sudo ip addr add 192.168.100.20/24 dev eth0 label eth0:1

# Bring interface up/down
sudo ip link set eth0 up
sudo ip link set eth0 down

# Add route
sudo ip route add 10.0.0.0/24 via 192.168.1.1 dev eth0
sudo ip route add default via 192.168.1.1

# Delete route
sudo ip route del 10.0.0.0/24
sudo ip route del default

# View routing cache
ip route show cache

# Multipath routing (load balancing)
sudo ip route add default nexthop via 192.168.1.1 weight 1 nexthop via 192.168.2.1 weight 1
```

#### Network Troubleshooting Tools

```bash
# Install network tools if not available
sudo apt install -y traceroute mtr netcat tcpdump

# Path MTU discovery
ping -M do -s 1472 google.com  # Maximum MTU test
traceroute -n google.com
mtr -n google.com  # Better than traceroute, shows real-time

# Bandwidth testing
iperf3 -s  # On server
iperf3 -c 192.168.1.100  # On client

# Capture traffic
sudo tcpdump -i any -n port 80
sudo tcpdump -i any -n -w capture.pcap  # Save for Wireshark

# Netcat (Swiss army knife of networking)
nc -l 1234  # Listen on port 1234
nc localhost 1234  # Connect to listening port

# Transfer file with netcat
# On receiver: nc -l 1234 > received_file.txt
# On sender: nc 192.168.1.100 1234 < file.txt

# Test TCP connections
timeout 2 bash -c 'echo > /dev/tcp/google.com/80' && echo "Port open"
```

### 3.4 DNS Deep Dive

DNS is critical—knowing how to troubleshoot it is essential.

```bash
# DNS resolution flow
# /etc/nsswitch.conf → /etc/hosts → DNS servers in /etc/resolv.conf

# View DNS configuration
cat /etc/resolv.conf
cat /etc/hosts

# Test DNS resolution
host google.com
nslookup google.com
dig google.com +trace  # Full resolution path

# Reverse DNS lookup
dig -x 8.8.8.8
host 8.8.8.8

# Query specific DNS server
dig @8.8.8.8 google.com
nslookup google.com 1.1.1.1

# List all DNS records
dig google.com ANY +noall +answer

# Check DNS propagation
dig +short google.com
```

#### Configure DNS Caching

```bash
# Install dnsmasq for local DNS caching
sudo apt install -y dnsmasq

# Configure dnsmasq
sudo tee -a /etc/dnsmasq.conf << 'EOF'
server=8.8.8.8
server=1.1.1.1
cache-size=1000
domain-needed
bogus-priv
EOF

# Point local DNS to localhost
echo "nameserver 127.0.0.1" | sudo tee /etc/resolv.conf

# Restart and verify
sudo systemctl restart dnsmasq
dig google.com  # Notice the query time improves on second query
```

### 3.5 Network Bonding (Link Aggregation)

For high availability and increased bandwidth:

```bash
# Install bonding module
sudo modprobe bonding

# Create bond interface configuration (netplan)
cat > /tmp/bond-config.yaml << 'EOF'
network:
  version: 2
  renderer: networkd
  bonds:
    bond0:
      interfaces:
        - eth0
        - eth1
      parameters:
        mode: 802.3ad
        mii-monitor-interval: 100
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
EOF

# Bonding modes:
# mode=0 (balance-rr) - Round-robin
# mode=1 (active-backup) - Active/passive failover
# mode=4 (802.3ad) - Dynamic link aggregation
# mode=5 (balance-tlb) - Adaptive transmit load balancing
```

### 3.6 iptables/nftables (Linux Firewall Deep Dive)

While UFW is a frontend, understanding the underlying netfilter framework is important.

```bash
# View current rules
sudo iptables -L -n -v
sudo iptables -t nat -L -n -v

# Basic filter table rules
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT  # Allow SSH
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT  # Allow HTTP
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT # Allow HTTPS
sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
sudo iptables -A INPUT -j DROP  # Default deny

# NAT (Network Address Translation)
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE  # Source NAT
sudo iptables -t nat -A PREROUTING -p tcp --dport 8080 -j DNAT --to-destination 192.168.1.100:80

# Save rules
sudo apt install -y iptables-persistent
sudo netfilter-persistent save

# Modern nftables (replacing iptables)
sudo nft list ruleset
```

## Part B: Storage Management

### 3.7 Linux Storage Architecture

```
Physical Storage (Disks)
    ↓
Partitions (fdisk, parted)
    ↓
LVM (Optional - Logical Volume Management)
    ├── Physical Volumes (PV)
    ├── Volume Groups (VG)
    └── Logical Volumes (LV)
    ↓
Filesystems (ext4, xfs, btrfs)
    ↓
Mount Points (/, /home, /var, etc.)
```

### 3.8 Disk Partitioning

#### Viewing Disk Information

```bash
# List all block devices
lsblk
sudo fdisk -l
sudo parted -l
ls -la /dev/sd*  # SATA/SCSI disks
ls -la /dev/vd*  # VirtIO disks (virtual machines)
ls -la /dev/nvme*  # NVMe SSDs

# Get disk details
sudo smartctl -a /dev/sda  # If smartmontools installed
sudo hdparm -I /dev/sda
```

#### Partitioning with fdisk (MBR)

```bash
# Create a test disk image (for practice)
dd if=/dev/zero of=test_disk.img bs=1M count=100
sudo losetup -f test_disk.img  # Create loop device

# Find the loop device
losetup -l

# Partition the disk
sudo fdisk /dev/loop0

# fdisk commands:
# m - help
# n - new partition
# p - primary
# 1 - partition number
# Enter - default first sector
# +50M - size 50MB
# w - write and exit

# Verify partitions
lsblk /dev/loop0
sudo partprobe /dev/loop0  # Inform kernel of partition changes
```

#### Partitioning with parted (GPT - Modern)

```bash
# Create GPT partition table
sudo parted /dev/loop0 mklabel gpt

# Create partitions
sudo parted /dev/loop0 mkpart primary ext4 0% 50%
sudo parted /dev/loop0 mkpart primary ext4 50% 100%

# Verify
sudo parted /dev/loop0 print
lsblk /dev/loop0

# Create filesystems
sudo mkfs.ext4 /dev/loop0p1
sudo mkfs.xfs /dev/loop0p2

# Mount and use
sudo mkdir -p /mnt/test1 /mnt/test2
sudo mount /dev/loop0p1 /mnt/test1
sudo mount /dev/loop0p2 /mnt/test2
df -h /mnt/test*
```

### 3.9 Logical Volume Management (LVM)

LVM is essential for enterprise Linux administration. It allows flexible storage management without repartitioning.

```bash
# Install LVM tools
sudo apt install -y lvm2

# Create physical volumes (PVs)
sudo pvcreate /dev/loop0p1 /dev/loop0p2

# List physical volumes
sudo pvdisplay
sudo pvs

# Create volume group (VG)
sudo vgcreate vg_data /dev/loop0p1 /dev/loop0p2

# List volume groups
sudo vgdisplay
sudo vgs

# Create logical volumes (LVs)
sudo lvcreate -n lv_root -L 50M vg_data
sudo lvcreate -n lv_home -L 50M vg_data

# List logical volumes
sudo lvdisplay
sudo lvs

# Create filesystems
sudo mkfs.ext4 /dev/vg_data/lv_root
sudo mkfs.xfs /dev/vg_data/lv_home

# Mount
sudo mount /dev/vg_data/lv_root /mnt/root
sudo mount /dev/vg_data/lv_home /mnt/home

# Extend logical volume (grow)
sudo lvextend -L +20M /dev/vg_data/lv_root
sudo resize2fs /dev/vg_data/lv_root  # ext4
# sudo xfs_growfs /mnt/root  # XFS

# Reduce logical volume (requires unmount and fsck)
sudo umount /mnt/root
sudo e2fsck -f /dev/vg_data/lv_root
sudo resize2fs /dev/vg_data/lv_root 40M
sudo lvreduce -L 40M /dev/vg_data/lv_root
sudo mount /dev/vg_data/lv_root /mnt/root

# Add new disk to volume group
sudo pvcreate /dev/sdb
sudo vgextend vg_data /dev/sdb

# Remove physical volume
sudo pvmove /dev/loop0p1  # Move data off first
sudo vgreduce vg_data /dev/loop0p1
sudo pvremove /dev/loop0p1

# Snapshot (for backups)
sudo lvcreate -L 10M -s -n lv_root_snapshot /dev/vg_data/lv_root
sudo mount /dev/vg_data/lv_root_snapshot /mnt/snapshot
# Backup from snapshot, then remove
sudo umount /mnt/snapshot
sudo lvremove /dev/vg_data/lv_root_snapshot
```

**🔴 RHEL Note:** LVM commands are identical on RHEL. This is a transferable skill.

### 3.10 Filesystems Deep Dive

```bash
# Create different filesystems
sudo mkfs.ext4 /dev/loop0p1
sudo mkfs.xfs /dev/loop0p2
sudo mkfs.btrfs /dev/loop0p3  # If btrfs-tools installed

# Check filesystem integrity
sudo fsck /dev/loop0p1  # Must be unmounted
sudo xfs_repair /dev/loop0p2

# Filesystem tuning
sudo tune2fs -l /dev/loop0p1  # ext4 parameters
sudo xfs_info /mnt/home  # XFS info

# Mount options
sudo mount -o noatime,nodiratime /dev/loop0p1 /mnt/test  # Reduce writes
sudo mount -o ro /dev/loop0p1 /mnt/test  # Read-only mount

# Permanent mounts (/etc/fstab)
sudo blkid  # Get UUIDs
sudo tee -a /etc/fstab << 'EOF'
# Format: UUID=xxx /mnt/data ext4 defaults 0 2
UUID=xxxxx-xxxxx-xxxxx /mnt/data ext4 defaults,noatime 0 2
EOF

sudo mount -a  # Mount all entries

# Find and mount by label
sudo e2label /dev/loop0p1 "DATA"
sudo mount LABEL=DATA /mnt/data
```

### 3.11 Swap Management

```bash
# View swap usage
swapon --show
free -h

# Create swap file
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Make permanent
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Adjust swappiness (0-100, lower means less swap usage)
cat /proc/sys/vm/swappiness
echo "vm.swappiness=10" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# Create swap partition
sudo fdisk /dev/sdb  # Create partition
sudo mkswap /dev/sdb1
sudo swapon /dev/sdb1
```

### 3.12 RAID (Software RAID)

```bash
# Install mdadm
sudo apt install -y mdadm

# Create RAID 1 (mirror) with two disks
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1

# Check RAID status
cat /proc/mdstat
sudo mdadm --detail /dev/md0

# Create filesystem
sudo mkfs.ext4 /dev/md0
sudo mount /dev/md0 /mnt/raid

# Save RAID configuration
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
sudo update-initramfs -u

# Failed disk simulation
sudo mdadm --manage /dev/md0 --fail /dev/sdb1
sudo mdadm --detail /dev/md0  # See degraded array

# Remove failed disk
sudo mdadm --manage /dev/md0 --remove /dev/sdb1

# Add new disk
sudo mdadm --manage /dev/md0 --add /dev/sdd1
```

### 3.13 Backup Strategies

```bash
# tar - The classic
tar -czf backup_$(date +%Y%m%d).tar.gz /home /etc

# rsync - Incremental backups
rsync -avz --delete /home/ /backup/home/
rsync -avz --exclude='*.log' /var/log/ /backup/logs/

# rsync over SSH
rsync -avz -e ssh /data/ user@backup-server:/backup/

# dd - Disk imaging
sudo dd if=/dev/sda of=/backup/disk_image.img bs=4M status=progress

# Disk cloning
sudo dd if=/dev/sda of=/dev/sdb bs=4M status=progress

# Automated backup script
cat > ~/backup_script.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/backup/$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# Backup important directories
for dir in /etc /home /var/www; do
    tar -czf "$BACKUP_DIR$(basename $dir).tar.gz" "$dir" 2>/dev/null
done

# Keep 7 days of backups
find /backup -type d -mtime +7 -exec rm -rf {} \;

# Log backup
echo "Backup completed: $(date)" >> /var/log/backup.log
EOF

chmod +x ~/backup_script.sh
```

### Scenario: Configure a Web Server with Proper Storage

```bash
#!/bin/bash
# Complete setup of web server with LVM storage

# 1. Create and configure LVM for web data
sudo pvcreate /dev/sdb
sudo vgcreate vg_web /dev/sdb
sudo lvcreate -n lv_webdata -L 5G vg_web
sudo mkfs.ext4 /dev/vg_web/lv_webdata

# 2. Create mount point and mount
sudo mkdir -p /var/www/data
sudo mount /dev/vg_web/lv_webdata /var/www/data
echo '/dev/vg_web/lv_webdata /var/www/data ext4 defaults 0 2' | sudo tee -a /etc/fstab

# 3. Install and configure nginx
sudo apt update
sudo apt install -y nginx

# 4. Configure website with custom document root
sudo tee /etc/nginx/sites-available/data-site << 'EOF'
server {
    listen 80;
    server_name data.example.com;
    root /var/www/data;
    index index.html;
}
EOF

sudo ln -s /etc/nginx/sites-available/data-site /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default

# 5. Create sample content
echo "<h1>Web Server with LVM Storage</h1>" | sudo tee /var/www/data/index.html

# 6. Configure firewall
sudo ufw allow 80/tcp
sudo ufw allow ssh
sudo ufw --force enable

# 7. Restart services
sudo systemctl restart nginx

# 8. Create monitoring
cat > ~/check_web.sh << 'EOF'
#!/bin/bash
STATUS=$(curl -s -o /dev/null -w "%{http_code}" localhost)
if [ "$STATUS" = "200" ]; then
    echo "$(date): Web server OK - Storage used: $(df -h /var/www/data | tail -1 | awk '{print $5}')"
else
    echo "$(date): Web server ERROR - Status $STATUS"
fi | tee -a ~/web_monitor.log
EOF

chmod +x ~/check_web.sh

# 9. Set up daily monitoring cron
(crontab -l 2>/dev/null; echo "0 9 * * * /home/ubuntu/check_web.sh") | crontab -

echo "Setup complete!"
```
