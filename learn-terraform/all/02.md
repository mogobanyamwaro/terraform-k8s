### Providers, Resources, and State

**Q1.** You see this block in a configuration:

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
```

What is the primary purpose of the `required_providers` block?

- A. Configure credentials for the AWS provider
- B. Tell Terraform which provider plugins and versions are needed
- C. Enable remote backends for the AWS provider
- D. Download all providers from the Terraform Registry every time

**Correct answer:** **B**

---

**Q2.** The version constraint `version = "~> 5.0"` on the AWS provider allows which of the following?

- A. Any 5.x or 6.x version
- B. Only 5.0 exactly
- C. 5.0 and any newer 5.x patch/minor (for example, 5.1, 5.99)
- D. 4.x and 5.x, but not 6.x

**Correct answer:** **C**
